# Harness 真实诊断实验：公开元数据

这是四批官方 Harness SDK 调用的匿名元数据，共65次实际调用：60次回执验收通过、5次达到输出上限而未完成；其中45次Max、20次Off，28次记忆生成、37次目标回答。四个故事均是已知开发材料，不能视为65个独立案例。

| 批次 | 范围 | 实际/计划上限 |
|---|---|---:|
| B01 | Off压缩与语境提示开发诊断 | 20/21 |
| B02 | Max固定记忆目标回答 | 12/12 |
| B03 | Max全局记忆与逐来源缓存 | 23/24 |
| B04 | 逐次核对预算的等最大生成输出预算补充 | 10/12 |

计划中未执行的4个槽位不计实际调用，也不计模型失败。B04在第11槽发送前被预算检查阻断。逐来源缓存的全部初次生成调用和token已包含在这些统计中；token用量不等于账户账单。

运行方式：

```console
python -B reproduce.py
```

该命令只用Python标准库核对公开文件哈希、白名单字段、token守恒关系及汇总计数。它不调用模型、账户或网络，不重跑真实实验，不认证未公开的原始回执，也不能复现答案正确率。哈希提供原始输入及回执的引用锚点，不替代独立检查其内容。

每行只有匿名槽位、批次、调用角色、模型别名、思考强度、输出上限、状态、单请求计数、token计数及输入/回执哈希。原文、问题、记忆、答案、人物标识、账户数据、会话标识与私人路径均未收录。

必须保留的结论范围：没有人工金标、独立留出集或已确立的新方法优势；真实SDK调用不等同于桌面会话可见。Off与Max比较还同时改变了输出上限；B03缓存初建为三次请求、全局为一次。B04只对齐最大生成输出token总预算，实际用量和请求数仍不同。五次输出上限失败均保留，不用成功样本替换。SDK回执也不能证明云服务隐藏上下文不存在。

模型路由别名为 `deepseek-flash`。本包不发布语义评分；语义结论需要另行审查同案例的私有原始材料及失败记录。
