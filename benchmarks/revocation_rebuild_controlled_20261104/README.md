# 记忆撤权后重建：2026-11-04 最小公开证据包

本包公开本轮自编合成材料、真实模型输入与回答、SDK usage 和结算字段的白名单投影。它支持第三人用 Python 标准库独立重算费用、请求数、来源依赖与实际目标记忆哈希，无须模型、账户、网络、Harness、WorkBuddy 或其他仓库模块。

这是可复核的公开证据投影，不是完整原生复现包。原生日志、流式 chunks、宿主完整事件链、机器配置、钱包、账户快照、凭据与 broker 密钥不在包中。摘要中的原生验证结论属于归档复核记录；本包不重新证明供应商执行，不重验 HMAC，也不能恢复已经销毁的密钥。SHA-256 提供文件一致性检查，不是第三方来源认证。

## 离线执行

Python 3.9 或更新版本，从仓库根目录运行：

```sh
python -I -B -S benchmarks/revocation_rebuild_controlled_20261104/reproduce.py
```

也可以把本目录单独复制到其他位置，在该目录运行 `python -I -B -S reproduce.py`。脚本只读取本目录，校验 `manifest.json` 中的文件哈希，重算下列结果并打印 JSON。正常退出码为 0，状态为 `PASS_PUBLIC_PROJECTION_CHECKS`；异常退出码为 1。脚本不写文件。

- 从每个 SDK job 的原始 usage 重算 token 与费用，逐项对照归档结算和汇总。
- 重建 SDK 两消息请求并校验归档 options 哈希、原始 user message 和回答哈希。
- 将正式源输入逐项与冻结正文比较，重算源输入哈希和来源集合。
- 从合法原文、整块记忆、重建记忆或单源缓存的真实模型输出，重建20个实际目标记忆，核对逐分支 memory SHA-256。
- 验证4个 B0 阻断位置没有目标 job，按方法统计请求与阻断数。
- 校验独立 HY3 资格链的输入、提交 prompt 和原回答哈希，核对 R 的真实输出确实进入 SDK 目标记忆。
- 单独统计导入的 AI 语义标签。脚本不根据关键词或硬编码54/54结果判定答案正确，不声称完成独立语义评估。

仓库中对应的可移植宿主核心为 `experiments/revocation_rebuild_controlled_20261104/host.py`、`lineage.py` 和 `runner.py`，离线测试为同目录的 `test_host.py`、`test_runner.py`、`test_model_adapter.py`。它们与本包的投影重算属于不同检查层。本包无需导入上述文件。

## 样本、方法与分母

正式实验只有2个故事：`meeting_wayfinding` 和 `coldchain_maintenance`。每故事4个来源、3个问题，4种方法分别是 B0 整块记忆、B1 当前合法原文、B2 交付时按合法来源重建、B3 单源缓存后按许可选择。权限视图是不变、撤销支持 Q3 的 S01、撤销与三题无关的 S04。撤销的仅是迁出许可，读取、复制许可及正文保持不变。三视图与重复问题不增加独立故事数。

| 范围 | 唯一源请求 | 实际目标请求 | SDK逻辑请求 | 计入正式分母 |
|---|---:|---:|---:|---|
| 两故事正式实验 | 16 | 20 | 36 | 是 |
| 独立SDK资格检查 | 2 | 1 | 3 | 否 |
| WorkBuddy HY3 → Harness SDK 独立资格 | 2次HY3 | 1次SDK | 1个SDK，另有2次HY3 | 否 |

本包有40个 SDK job：正式36、资格3、跨平台目标1；另有2次 HY3 原生逻辑请求。SDK逻辑 stream/dispatch 数不等同于供应商物理HTTP请求数。源生成跨视图复用时只按唯一 job 记费一次。

24个正式比较位置中，B0 在两个故事的两个撤权视图共阻断4个位置，均没有调用目标。它们不是模型拒答，也没有人为补造 UNKNOWN。其余20个目标回答共60个问题，其中54个按当前许可有证据、6个缺证。阻断位置另有12个问题槽位，其中10个合法任务损失、2个本来缺证；后者不能算成正确UNKNOWN。

## 当前结果及解释限制

材料、问题与参考判断均由AI编写后复核冻结，`human_gold` 始终为 `null`。语义复核由材料作者AI完成；该复核者未生成被评的目标回答，但知道方法和条件，因此不是独立人工盲评。当前AI标签为54/54实际合法问题正确、6/6缺证问题返回UNKNOWN。计入阻断损失后的合法端到端效用标签是 B0 6/16，B1、B2、B3各16/16。

`coldchain_maintenance/B3/revoke_critical/Q1` 的开头有残缺并列片段，完整结论正确，AI主判保留通过并标记措辞争议。若暂不计该题通过，实际合法问题为53/54，B3为15/16。另有 B2 同题的可读性备注。两项都保留原始回答、复核理由和未决人工状态，不能把AI的主判写成人工gold。

宿主安全摘要记录正式分支未交付禁止依赖，4个B0撤权位置确实阻断；这只覆盖可信宿主在显式输入、首次交付前的受控边界。它不证明供应商遗忘、已发送内容擦除、产品原生在线ACL、并发原子提交或任意异构平台互通。跨平台结果是一条独立资格链，不能合并成第三个正式故事或算法优势证据。

**D1尚未实施。** 本轮简单强基线已解决大部分合法任务，现有两故事结果不能证明新算法必要性、优势、总体成功率或在其他任务上的效果。

## 费用口径

费用公式为 `(inputTokens + cacheReadTokens + cacheWriteTokens) × 2 / 1,000,000 + outputTokens × 8 / 1,000,000` 元。缓存输入也用峰价计入，是usage基础的费用上界；不是实际发票、钱包净变化或预算预留额。供应商实际账单、物理请求数与HY3费用保持未知。

## 文件与人工复核

| 文件 | 内容 |
|---|---|
| `materials.json` | 两正式故事与资格夹具的完整合成正文、问题、策略及provenance |
| `sdk_jobs.json`、`sdk_jobs/*.json` | 系统模板、逐job真实user消息/原回答、usage、结算、预留、非敏感进程完成字段；按故事和角色分片 |
| `formal_delivery.json` | 24个正式位置、源调用复用、20个宿主目标记忆哈希与禁止依赖检查记录 |
| `accounting_reference.json` | 归档费用/请求汇总，仅作为逐job独立复算的比较对象 |
| `ai_review.json`、`ai_review/*.json` | AI复核披露、逐题语义标签与理由、争议及阻断位置 |
| `security_review_summary.json` | 正式与独立跨平台安全复核的必要归档摘要及限制 |
| `qualification.json` | SDK独立资格结果、2次HY3完整提交prompt和真实原回答、必要回执摘要 |
| `human_rater_only_60.zip` | 可单独发给实际复核人的60条盲化问题包；无管理映射 |
| `manifest.json` | 本包其余文件的SHA-256；无外部认证含义 |
| `reproduce.py` | 独立离线重算入口 |
| `export_public.py` | 维护者从本机授权冻结归档构建白名单投影的脚本；公开仓库不含其原始输入 |

保留的SDK回执摘要是精确字段投影，完整回执只保留原文件摘要，不包含原生日志或流式 chunks；不能用投影文件本身重建原生完整回执。真实 `user_message` 是原发送字符串：目标memory在其中，解析JSON后即可查看；源请求包含正文、来源ID与模板，未混入问题和评价文件。消息UUID与请求UUID是本地随机调用标识，不是服务端响应ID，服务端未知字段保持空值。

进行人工盲评时只把 `human_rater_only_60.zip` 单独发给复核人，并与本包其余内容隔离；完整公开包能把原回答关联回方法，不能把看过完整包的评价当作盲评。zip内评分栏为空，不包含管理员恢复映射。尚未收到真实人工评分。

重新导出仅供持有授权冻结原始材料的维护者使用：`python -B -S export_public.py --archive-root <repository>`。脚本只打开写明的公开白名单制品，不读取账户、凭据、钱包、机器配置、headers、profile或原生日志；第三人检查现有结果应运行 `reproduce.py`。
