# 投稿验收有限合同 v1

冻结日期：2026-10-30。本合同是当前研究原型的可检验规格，不是通用Agent迁移协议、形式化证明或SCI统一门槛。若要扩大支持类型，需新增合同版本与案例，不能修改旧参考答案。

## 参与方与信任

用户alice与bob、源Agent标识qoder、目标Agent标识harness相互区分。迁移主机、配置中的确切用户—Agent授权对、原始源文档和本机当前状态服务可信。云模型及其回答不能授予权限。恶意用户可以提出越界请求、伪造代号、尝试旧请求重放；不假设攻击者已控制迁移主机或取得签名密钥。

源材料为Qoder适配格式的合成源夹具，由主机建立确切片段记忆；本轮不从Qoder私有数据库自动抓取记忆，也不声称Qoder模型生成了这些事实。真实目标实验调用已安装的DeepSeek Harness，单次新进程、新工作区、禁工具、最多64输出token。源标识和目标标识是主机合同的一部分，静态AGENTS.md没有原生逐对象ACL。

## 请求和操作

请求显式绑定user_id、agent_id、operation、resource_id、source_id、audience、model_recipient、policy_version、now。用户—Agent必须按确切配对授权，不展开成两个独立集合的笛卡尔积。固定audience=harness、model_recipient=harness-model-provider、policy_version=journal-v1。now是受控实验的整数逻辑时间，区间[0,200)，并非真实生产时钟同步协议。

- read：当前主体对该记忆有读取许可。
- handoff：源alice/qoder可读，目标alice/harness可读，且export_allowed、copy_allowed严格为True。
- restore：目标当前可读，且restore_allowed严格为True；实际恢复还必须来自本次已通过handoff的完整准备记录。
- 未知/缺失/错误类型不交付；已知违反必要约束优先拒绝。参考的四值与接口错误码分开，不主张它们逐字语义相等。

允许读取不自动允许迁出或恢复。仅EMAIL为本批实际评测的敏感类别；生产接口还配置PERSON，本批没有人名检测的有效性主张。内部口令的禁止迁出来自独立授权，不能拿邮箱检测器作为业务秘密发现能力。

## 交接链与性质

| 性质 | 强制执行 | 参照与证据 |
|---|---|---|
| P1 确切来源 | 原文半开区间与source_id核验，建立签名记录 | 独立reference.judge原文检查、来源篡改测试、source_bindings_verified |
| P2 无授权扩大 | 每条fact检查原生read与broker许可后选取 | 手写授权对照、有限矩阵W+；授权缺失不填允许 |
| P3 保护不删权限 | 实际规则检测后，生成标注与迁移检测在two_stage接口联合 | 记录实际findings、保护载荷、独立敏感区间金标；不使用回放检测 |
| P4 问题同步保护 | 问题和记忆共同准备，代号只在本次请求有效 | 题面邮箱案例、query-only伪造与跨事务代号测试 |
| P5 目标输入绑定 | broker先验包，保护载荷冻结，写入并重开AGENTS.md | 文件hash；真实Harness另存native_instruction_loaded及加载事件 |
| P6 再核权与撤销 | 恢复前再验包、所有保留记录的当前read/handoff/restore | 包括UNKNOWN的撤权/未知/重复恢复测试、动态矩阵。旧明文不被事后遗忘 |
| P7 失败不冒充安全 | 无回复/处理失败/未知与拒绝分开，使用全部计划分母 | 独立score关闭后评分，载荷/原始回复/最终回答分别审计 |

恢复映射、签名能力与凭证不得进入日志或复核包。共享相同输入的基线结果属于关联观测：保留各自本地恢复状态并显式关联实际调用，不能增加独立样本数。未知代号与只有问题提供、没有记忆证据的原值不能恢复为事实答案。

## 支持边界和验收

仅确切片段、单事实值或UNKNOWN；不支持自由摘要、多源派生依赖发现、全程序信息流证明、任意业务工具或任意平台ACL转换。有限枚举通过仅覆盖登记的主体、操作和边界变体；本机受信主机通过不代表任意恶意接收Agent不能保存已交付内容。

开发3故事、检查6故事，全部AI辅助自编，评分答案另存references.json。运行器不打开答案，预测封存hash验证后独立评分。开发中已实际执行失败的两轮结果保留；后续观察本批结果后，该批已是暴露材料，不能再作新算法的盲测保留集。人工标注复核及真正外部人员验收均未完成。

基线为整请求阻断、逐片段处理、已有选择性隔离，共享相同原始材料、权限、实际检测器、提示和预算。本批没有新的候选算法，不把基线之间相同输入的结果包装为方法创新。

第三方复核分两层：无网络重算已记录响应与指标；重新运行本地链建立新临时密钥和状态。重新调用在线模型需独立预算、账号和服务版本，不能保证模型返回逐字相同。正式复核包应按文件hash固定源码，不能只写一个未包含最新未跟踪文件的旧git提交号。

研究制品原则参考[USENIX Security 2026](https://www.usenix.org/conference/usenixsecurity26/call-for-artifacts)：可获得、可运行、结果可复现是不同维度。它要求长期托管，GitHub本身不满足其永久制品平台要求；本项目当前先提供本机可审查包，不宣称已获得会议徽章或满足所有期刊要求。
