# 首次交付前撤权：有界实验入口

已完成一例可观察的真实 WorkBuddy HY3 → 可信宿主 → DeepSeek Harness G0—G4 链。AI 核对的两道合法题完整回答，撤源控制题为 UNKNOWN；完整 SDK 正文未保存，全面隐私验收仍未建立。旧失败、参考和生产默认保留。

- [执行合同](contract.md)：参与方、许可、真实时序、证据和预算边界。
- `driver.py`：复用 NativeAgentBroker，分阶段生成/封存、撤权、旧包拒绝、再核权提交。一个持续存活的 Python 对象，不支持崩溃续跑。
- `analyze.py`：检查事件记录；识别全混合 AND 及普通独立缓存的退化情况。不产生模型效果或新算法优势。
- `test_driver.py`：17 项离线定向测试，包含过期与撤权区分、请求绑定、会话分离、最终版本变化、未知发送不重试，以及禁止字符串冒充可信标志。

在仓库根目录运行以下标准库离线检查，不会调用模型：

```powershell
python -B -X utf8 -S -m unittest experiments.pre_delivery_revocation.test_driver -v
python -I -B -S benchmarks/pre_delivery_revocation_metadata_20261101/reproduce.py
```

本轮首版16项检查、修订版17项检查均在固定a9a710b隔离副本及明确覆盖层运行通过；修订版不覆盖首版。工程检查不计作模型效果。公开包提供保存结果的离线重算，不重新运行云端请求。

真实接入需要可信适配器记录 WorkBuddy 的实际显式输入、输出和独立 HY3 会话；R 生成在实际撤权及旧包拒绝之后。`seal_M` / `seal_R` 不能接受模型自己编写的回执。目标回调只收到 R，不得在回调内另送 M。

本轮首次真实资格已提交一个源作业；原生客户端产生了晚到记忆，但宿主结果同步失败，未在活驱动内封存M，因此没有执行撤权、R或目标调用。失败及晚到证据分别保留在 `live_chain01/run01/` 与 `live_chain01/late_observation01/`。不能把晚到文件重新放进新Broker追认时序。28/16是本轮研究总边界，当前一次性入口没有提供跨任意新输出目录的全局调度/计数平台；本次仅消耗1个源逻辑位置。

随后另开新资格运行，使用两个新原生HY3会话：M封存后实际撤销S01.export，旧M未过期而被两路径拒绝；R只收到合法S02—S04，再核权后交付真实Harness SDK。目标guard记录7209字节、256输出上限、工具0、一次stream；原生R记忆3071字节。合法题完整2/2、主动拒答0/2、撤源UNKNOWN 1/1，属于一个已暴露故事和AI评审。生命周期源位置3/28（含此前失败），目标1/16。完整SDK额外上下文排除、源语义质量及人工最终验收仍未通过全部检查，不声称新方法优势。
