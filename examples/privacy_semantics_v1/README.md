# 语义保留隐私评测材料 v1

冻结日期：2026-10-25。本目录是为本项目下一轮实验自编的受控合成材料；机构、业务记录和问题均为虚构，不是企业数据、公开标准基准或人工招募的用户样本。24条故事的源文、问题和参考答案均逐条编写；文件生成过程只计算位置、校验一致性并序列化，没有调用模型产生答案。

## 数据划分

- `development/`：8条故事，中英文各4条，4个双语叙事模板族。可用于机制开发和诊断。
- `heldout/`：16条故事，中英文各8条，8个双语叙事模板族。模板族与开发集不重叠；算法、提示词、阈值、预算、对照方法和验收口径冻结后才能运行正式评测。不得根据保留集结果再调整本版本后重新称为保留成绩。
- 每故事有4道合法单事实题（客户全名、非敏感事实、问题含客户值后询问事实、泛称改写的客户提问）和1道越权题。每个条件开发32道合法题/8道越权题，保留64道合法题/16道越权题。

同一个故事的多题、多个模型条件及重复运行不是独立故事；相同叙事模板的双语版本也有依赖。应同时报告故事数和模板族数、按语言分层及共同可处理任务上的配对效果。该规模用于诊断与机制测试，不支持普遍安全或论文创新声明。

## 运行输入与评分隔离

每个划分的 `runtime.json` 只含源文字、静态类型策略、用户身份和问题。`evaluation.json` 单独保存正确答案、敏感片段、公开组织片段、问题中的敏感位置和统计特征；不得将该文件、参考答案、片段标签或特征输入检测器、记忆构建器、回答模型或用来选择回答候选。

接口基本兼容现有 `ner_benchmark` 的故事/任务结构，额外提供 `paraphrase` 合法任务。`status` 是沿用的任务标识，实际可问业务阶段、结果、仓储分类或日期；不能按任务标识直接生成答案。所有参考答案在各自源文中有逐字证据，但它们不会出现在运行文件中的额外事实字段内。

客户名称为受保护的 `CUSTOMER` 实体类型，包含明确记载的旧客户名；泛称、业务状态、交期和公开的非客户组织不属于此基准注册敏感片段。类别型检测器保守地遮蔽全部组织可以单列比较，但必须统计额外遮蔽。规则说明中的保密标签不授予读取权限。越权用户仍应在宿主核权层拦截，不能因为检测器返回空实体而放行。

包含多组织、同前缀不同实体、中文全角标点、中英文混排、客户更正历史以及不可信文本内的指令。除CUSTOMER外的其他隐私类别不在本数据的覆盖声明中。所有故事的原始授权由实验宿主独立设置（owner允许、outsider不允许）；这不是从真实业务系统收集的ACL。

## 冻结和计分注意事项

`manifest.json` 记录两个划分四个数据文件的原始UTF-8字节哈希及验证统计。原文保留Unicode原字符，位置采用Python字符串的零基、左闭右开字符索引；不是UTF-8字节偏移。加载时应核验哈希，不规范化、裁剪或重写源文。

建议分开报告：敏感片段完整召回/精确率，额外遮蔽字符与公开实体误遮，问题与记忆各自漏遮，待审/预处理阻断，真实模型UNKNOWN，恢复阻断，合法正确率，越权外发与最终披露，以及本地调用、延迟和云费用。正确率分母保留所有合法题，不能只报准备成功的题。检测时不保存或打印恢复映射。

该材料没有执行任何检测、构建或回答模型，因此没有模型效果结果；静态位置与源文包含检查不等于隐私验收。
