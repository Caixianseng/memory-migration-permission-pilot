# 九类敏感检测材料 v1

本目录另含120条新自编材料：80开发、40保留，各自中英文等量。未复用上一级24故事，因此 `shared_story_id` 均为null；也未使用之前正式八故事的模型输出或此前120条词表。未调用任何模型、云API或人工众包服务。所有名称和业务字段均为研究用虚构值，不与真实个人或客户关联；电话号码的格式外观不表示已验证可用或归属。

九类为CUSTOMER、PROJECT、PERSON、ADDRESS、EMAIL、PHONE、ID、AMOUNT、DATE。`runtime.json`含case_id、语言、模板族、policy和payload（query/memories），不含评分标签。`evaluation.json`按case_id存原始源标识和敏感片段位置、配对ID和统计特征；只能用于评分。位置是原文Unicode字符的左闭右开索引，包装引号、尖括号、字段分隔符不计入值；公司法定后缀、金额币种和单位包含在指定值中。部分中文ID为明确标注的证件格式字符串，本材料未逐项核验地区码、出生日期或校验位；算法不得把无效校验直接等价为不敏感。邮箱使用保留的.example域名；检测是否敏感与地址是否真实可投递分开。

每个类别包含私有类别策略与显式公开策略的同文本配对。公开策略protected_categories为空；这测试宿主是否遵守当前策略，不要求实体识别器从文本推理复杂业务条件。配对材料共享payload，不能当成两个独立内容样本。还有一般角色词、以同样词语作为完整虚构专名的反例，以及只在用户问题中提供私有值的材料，避免只扫描记忆正文或通过固定泛称白名单达到高分。

泛称作为机构真名的病例故意是明确登记的虚构边界案例，可能不同于自然企业名称分布；必须单列报告。公开策略结果为空也不能说明底层文本无实体。类别检测能力、当前敏感策略、用户读取权限是三个不同问题；本数据只为前两个提供受控标签。

开发/保留按模板族隔离。模板族在同一划分内跨类别及双语重复，因此120条不是120个独立故事。manifest记录材料数、内容去重数、配对数、分语种数量和类别片段数。标签已做源文位置及类别一致性程序检查，但尚未独立人工复核；有争议时应保留原版、记录争议并作另版，不得在看过实验结果后静默改标签。

使用保留集前冻结代码、提示、阈值、方法组合与验收门槛。逐片段完整召回/精确率、待审率、额外遮蔽与耗时应同时报告；阻断材料不视为已经成功检测。保留字段类别与模板族细分结果，不能把公开策略产生的大量空标签当作总体隐私效果证据。本目录没有效果分数。
