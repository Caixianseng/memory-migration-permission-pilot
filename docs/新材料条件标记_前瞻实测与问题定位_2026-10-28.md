# 新材料条件标记：前瞻实测与问题定位

日期：2026-10-28。方法及材料于 10 月 27 日冻结，执行目录保留原日期编号。**条件标记在新合成材料上改善了分类，但仍有真实的漏遮载荷，不能通过安全验收或切换默认流程。**

## 1. 本次检验的范围

这是记忆安全迁移流程中“送入模型前的敏感检测与脱敏”环节测试，没有重新运行原生跨 Agent 迁移，也没有让下游模型回答任务。原来的迁移权限、稳定性和论文创新要求保持不变。

先冻结路由方法、候选模块及预注册说明，再由没有前序对话的独立作者编写 24 条新材料：英文和中文各 12 条，每种语言覆盖当前客户、历史客户、明确非客户、关系未知、普通角色词、同词不同含义六类。另一子任务在不读预测的情况下审查标注，未发现必须阻止运行的结构或明显语义错误。

这批材料是 AI 辅助编写和复核的受控合成诊断集，不能称现实独立数据、人工标注共识，或原要求中的独立 64 题验收。评分标签始终与模型输入分开，预测及实际脱敏足迹封存后才打开标签。

## 2. 固定方法与实际调用

固定规则只检查本地实体提取器返回的候选：如果不同位置的候选有完全相同的原文字串，则使用位置标记；否则使用普通输入。没有按答案或模型结果选择方法，没有补充人工名称，也没有修改旧分数。

本次重新运行固定 GLiNER，实际 **24 次实体提取调用**。普通输入运行 24 次本地 Qwen；五条材料触发位置标记，各增加一次生成，共 **29 次生成**。其余 19 条条件组结果直接共享同一普通输入观测，明确记录为复用，不能当作额外独立实验。

另外有四次本地版本/模型检查，总计 33 次回环连接、0 次外部连接尝试。输入 token 共 12,000，输出共 663；总执行时间 50.968 秒。没有云端调用、付费 API、原生写入或修复重试。

条件组增加了三个完整正确案例，且没有减少可准备数；但唯一漏遮在两组都存在，精确率与召回率也仍低于 P90/R95。按 [预注册](新材料条件标记_前瞻检验预注册_2026-10-27.md)，推进门槛为 **未通过**。没有进行显著性或总体安全性推断。

## 4. 主要问题已经定位

### 候选漏检和空列表被接受

第 22 号材料先把“苔藓”用作植物词，后明确说另一处“苔藓”是一家机构的完整名称，且正在向本公司购买展示柜。实体提取器返回 `organization=[]`，没有产生任何候选。

后续分类器被要求只处理给定候选，因此返回空结果；当前准备层接受了这个空结果，生成未遮蔽正文。由于路由只看候选，重复名称条件也无法触发。

这是一处**候选召回与空候选语义校验缺口**。请求身份、位置绑定、哈希及 JSON 格式检查都可以通过，却不能证明正文没有敏感实体。本次没有把该载荷发往云端，所以应表述为“已准备载荷存在漏遮”，不能声称已经发生外部披露。

### 两个关系误报

条件组剩余两个精确误报都发生在正确的机构名称位置：

- 将明确从未向本公司购买的供应商误判为历史客户。
- 将“既不是现有客户，也从未采购”的组织误判为历史客户。

这属于关系方向或否定语义判断错误，不是实体名称边界错误。只调整位置标记不能解决它们。

### 一处重放接口注意事项

候选字典保存时使用排序键，重新读盘后键顺序与原提取器构造顺序不同；而请求中的候选 JSON 字符串未规范化排序。直接重建可能产生语义相同、字节不同的请求及哈希。

独立审计以实际传输捕获中的字符串为准，并按已冻结提取器的原字段顺序重建后核对通过。该过程没有修改预测或指标，但**不能据此宣称任意序列化重载都能逐字节复现**。请求序列化规范化仍是后续工程修复项，应在新版本中验证，不能静默改写本次冻结实现。
