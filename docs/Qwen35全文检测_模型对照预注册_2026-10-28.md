# Qwen3.5 全文检测：模型能力开发对照预注册

日期：2026-10-28。目标是检验固定全文识别方法的失败是否受模型能力限制。这是安全记忆迁移原型中的检测工程基线实验，不认定换模型或组合已有模块为论文创新，也不替代原独立自然语言检测、64题、原生环境和下游Agent验收。

**正式生成仍为0时的资源修订：** run03主权重达到约1.9GB/2.65GB时，实际速率降至约1.2MB/s，剩余估计约10分钟，原每窗900秒不足。此前“run03后不再恢复”的资源安排由此修订，保留其历史决定与失败记录：如run03超时，最后允许run04复用已验证的同一服务和缓存，最多1500秒。四个窗口的理论上限总计4200秒（前三次各900、最后1500），不再自动增加窗口。该修订发生在运行资格及正式生成之前，只调整下载资源；任何效果失败仍不得通过追加模型、改提示或更改金标补救。

## 2. 冻结方法与比较条件

复用`OccurrenceQwenAgent`的SYSTEM_PROMPT、REPAIR_PROMPT、输入规范、完整政策、输出schema、原文出现位置解析及预算规则。新增适配器显式绑定新模型和完整摘要，发送顶层`think:false`，拒绝实际思考/工具调用、非stop结束与超预算输出。不得伪造旧模型别名或修改旧全局常量。新旧tokenizer及模板不同是模型包差异，不能称相同实际token序列。

每条同样使用全文和空`rule_findings`；本轮不新增NER候选、不改提示、不调整阈值。与旧最强条件位置分类器的比较是不同识别方法的工程比较，模型能力归因仅由两个全文条件支持。

| 条件 | 输入及响应 | 本轮生成 |
|---|---|---:|
| `qwen3_fulltext` | 上轮`source_annotations.json`中Qwen3 4B真实全文响应 | 0，历史回放 |
| `qwen35_fulltext` | 相同全文方法和政策，Qwen3.5 4B真实响应 | 每条1次，格式/定位错误最多再1次 |
| `qwen3_conditional` | 上轮`receiver_responses.json`中最强条件位置响应 | 0，历史回放 |

三条件分别进入相同主机权限及真实假名化准备接口：空源标签、migration模式、精确同一用户/Agent授权。**不合并三个条件的正标签**，避免把多检测信息增量或旧误报强制并入新模型结果。每个可准备结果另检查错误用户和错误Agent必须拒绝。

## 3. 材料与封存顺序

固定复用`results/source_annotation_20261028_run_01/`中的24条已暴露中英文开发正文、政策和参考；历史源码/输入/响应先按封存摘要核对。不把它们称为独立保留材料或新现实样本。

本轮执行完整24条单批次，不采用上一份建议中“可采用”的12→24效果门控：完整批次便于在全部预测关闭后再评分，不将阶段分数反馈到未完成预测。运行资格失败、硬预算或执行错误仍必须停止，并保留已有结果及失败分母，不能补跑成另一批成功记录。

`plan-only`冻结完整模型资产和运行资格收据、输入/参考不透明文件摘要、三条件历史响应、代码、政策、提示、schema及请求绑定。`execute`要求成功资格已在计划中固定，以独占开始文件和计划摘要防止重复启动；每条执行前核对输入与源码未变。预测、模型响应、HTTP捕获和实际遮蔽足迹全部关闭后，才解析评分参考。新模型、适配器或提示更改需要新计划及独立结果目录，不能覆盖原结果。

## 4. 硬预算与失败处理

- 正式新生成最多48次：24条，每条最多2次；第二次仅按既有逻辑修复格式或位置，语义不确定不触发追加调用。
- 独立运行资格最多1次；本轮总新增生成最多49次。旧响应回放不得计为新的本地生成。
- 4096上下文、1024最大输出、temperature=0、seed=42；实际输入/输出token、修复次数、等待及耗时分别报告。禁止静默截断。
- 成功生成的实际`prompt_eval_count`及`eval_count`必须是非布尔整数，分别在0—4096及0—1024范围内；缺失、越界或未完整结束的原响应仍封存，不能把成本记完整或把该次资格记通过。
- 仅固定本机端口；0云端、0付费请求、0下游模型、0原生后端写入；正式执行最长1800秒。
- 外部模型资产下载与正式推理的网络行为分开；正式推理只允许回环。失败保留原响应和诊断，不通过改参考、放宽政策或清除待审提高成绩。

## 5. 指标与开发推进门槛

分别报告原始精确位置TP/FP/FN、P/R；known/unknown、可准备、准确且可准备、真实遮蔽足迹、已准备漏遮、多遮蔽非敏感字符、指定合法事实保留、语义待审与工程失败、身份反例和费用。原始位置分数包括被阻断known响应中的正位置，必须与真实输出足迹区分；阻断不能算成功遮蔽。需要同时保存分母与逐例记录。

新模型的24条开发推进门槛同时要求：

1. 原始精确跨度P≥90%、R≥95%；
2. 已准备载荷中的参考敏感漏遮为0；
3. known可准备不少于相同24条旧条件位置强基线（当前18/20）；
4. 参考未知4条均有实际语义不确定证据且阻断，不用格式失败冒充正确待审；
5. 可准备输出的错误用户、错误Agent反例均拒绝，实际调用及成本计数完整。

运行资格通过不是效果通过；开发门槛通过也不是原独立P90/R95验收通过。否则保留失败并定位，不能自动追加另一个模型或改提示以刷分。真实下游问答和拒答未运行时保持未测，不能从合法事实保留推导问答改善。

## 6. 原研究目标及强基线约束

完整目标仍包含新独立检测与64题联合成功、原生迁移和历史环境问题闭环、真实下游Agent、充分强基线和可复现创新。换更强模型属于应有工程基线；如果权限和迁移机制仍与完整标准方案等价，论文创新继续保持未成立。
