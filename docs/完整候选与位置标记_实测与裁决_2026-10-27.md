# 完整候选与位置标记：实测与裁决

日期：2026-10-27。结论：取消任意的两候选阻断后，当前直接分类开发结果改善；给所有候选加位置标记出现效用退步，未通过预注册的采用条件。没有切换默认方法，也没有完成论文验收。

## 实现和执行

新增 `candidate_context_batch.py`，核对旧候选池与原生提取捕获，逐项从原始返回重建全部候选。保留旧状态和结果，仅在新合同中允许最多 12 个候选，并对实际完整输入预检。没有补充评分名称、修正实体边界或丢弃多余候选；“完整”只指保留提取器实际返回的库存，不证明没有真实实体漏检。

比较完整原文（plain）和候选出现位置标记（marked）。两臂的系统提示、全部候选、输出类别、固定模型和预算相同，只有原文中的位置标记不同。去除标记严格恢复原文；恢复映射仍使用原文位置，标记不进入迁移记忆。重叠或伪标记输入在两臂都阻断。

使用原先已曝光的 12 条开发材料，两臂各 12 次，共 **24 次本地 Qwen 生成**，另有 4 次本地版本/摘要检查。全部正常结束，未修复重试、未请求云端或原生后端。总执行时间 7.86 秒。输入预检最大上界为 plain 3341、marked 3440，均小于固定 4096 上下文界限；该值含 1024 输出预留，是保守字节估计，不是实际 tokenizer 测量。

## 实际结果

| 指标 | 完整候选、不加标记 | 完整候选、加位置标记 |
|---|---:|---:|
| 确定案例完整正确 | **9/10** | 8/10 |
| 确定案例可准备脱敏请求 | **9/10** | 8/10 |
| 未知案例正确待审 | 2/2 | 2/2 |
| 未知案例错误当成非敏感放行 | 0 | 0 |
| 精确敏感片段 TP / FP / FN | 5 / 0 / 1 | **6 / 0 / 0** |
| 精确率 | 100% | 100% |
| 召回率 | 83.3% | **100%** |
| 实际完整遮蔽参考敏感片段 | 5/6 | **6/6** |
| 已准备载荷中遮蔽不完整的参考片段 | 0 | 0 |
| 保留合法事实原文 | **9/12** | 8/12 |

**100% 召回仅来自这组已曝光材料中的 6 个敏感片段。** 它不是总体隐私保证，不是独立验收，更不是下游合法问题回答成功率。plain 中未覆盖的一处敏感片段随请求阻断，没有被发送给云端；仍计入漏检分母。

旧两候选合同下的直接分类为 7/10 确定案例正确。本轮两条旧超限输入均通过，但本轮还共同增加了标记说明，因此历史比较属于开发诊断，不能把所有分数差异严格归因于单一参数。有效的标记效果对照是本批两个同时运行的条件。

## 错误在哪里

- 第 0 条的三个候选包括两家机构和 `our company`。新两臂均正确区分客户、非客户与普通指代，不再仅因第三个候选阻断。
- 第 5 条同时出现普通词 `splice` 与同名组织。plain 仍对普通词位置待审；marked 正确区分了两次出现。
- 第 4、10 条只介绍角色名称。plain 正确判为普通词；marked 对英文 `supplier/customer` 或中文“客户机构”返回组织关系未知，造成不必要阻断。
- 两个真正关系未知的案例都保持待审，其中一个自动候选边界仍只有“联盟”。本轮没有修复这个名称边界，因此不能宣称通用实体检测已完成。

位置标记提升了这组正例召回，却使两个负例退步。按 [预注册](完整候选与位置标记_开发对照预注册_2026-10-27.md)，确定案例完整正确和可准备数不得下降；marked 未通过。不能按每条参考答案挑选较好的臂拼成“100% 成功”，也不能删除角色词案例来提高结果。

## 验证与复查

运行前 **76 项针对性测试通过，0 失败、0 错误，0.931 秒**，包括 18 项新模块边界测试和 4 项新驱动测试。这不是全仓 CI。原始生成和实际脱敏足迹先封存，参考文件后读取；评分不以秘密完整字符串消失替代实际位置覆盖。

独立只读复核检查了计划、预测、封存记录及 28 份传输捕获的哈希；确认去标记后原文一致、完整候选与共同配置一致。全部原始响应重新解码、实际遮蔽足迹重放和评分复算均与保存报告一致，没有新增模型或网络调用。实际输入/输出 token 分别为 plain 4823/274、marked 5163/274。

## 对完整研究目标的判断

当前证据支持继续保留完整库存与长度检查这项工程修正，但不支持对所有候选默认加标记。两臂仍分别存在漏检或合法内容不必要阻断，不能宣称已达到综合验收。

位置标记是既有关系抽取方法，本轮属于适配验证。[Matching the Blanks（ACL 2019）](https://aclanthology.org/P19-1279/)、[改进关系抽取基线（AACL 2022）](https://aclanthology.org/2022.aacl-short.21/)。论文创新证据尚未成立。

仍待完成：独立材料上的检测 P≥90% / R≥95%、新独立 64 题至少 63 题联合成功、真实 Agent 下游效果、历史 HTTP 200/null 原因与环境稳定性。不能用本轮 24 次分类请求或 76 项测试替代这些要求。
