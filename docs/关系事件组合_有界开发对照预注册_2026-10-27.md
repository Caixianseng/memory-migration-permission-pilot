# 关系事件组合：有界开发对照预注册

日期：2026-10-27。问题限定为本地隐私检测中的客户关系判断，不改变权限协议、默认检测路径或既有评价真值。

## 假设

当前直接判断可能混淆“以前是客户、现在不是”、供应方与采购方、公司名称与角色词。拟把判断拆成：从原文提取双方、方向、肯定/否定、时间范围和证据，再由程序组合。原文位置校验只证明引文存在，不证明模型理解正确。

“当前不是客户”不能抹掉肯定的历史客户事实；供应方也不自动等于从未是客户；相互矛盾或证据缺失需要待审。所有判断针对预先固定的业务主体，不让记忆文本创造权限。

## 三个条件

| 条件 | 输入 | 处理 |
|---|---|---|
| direct | 完整原文＋同一自动候选池 | 本地 Qwen 直接分类 |
| rules | 完整原文＋同一自动候选池 | 固定角色与买卖方向规则，无模型调用 |
| events | 完整原文＋同一自动候选池 | 本地 Qwen 提取事件，宿主校验与组合 |

规则臂覆盖其明确实现的语法；不是所有自然语言的完备解析器。事件法即使超过它，也须继续与直接模型和其他完整检测方法比较。

使用已有 12 条中英文开发正文和旧实验封存的自动候选，不从参考标注提供组织名称或片段。材料已曝光，不能称独立保留集。沿用最多 2 个候选的合同；原池超限的 2 条正文在三臂中均记覆盖不足，完整保留分母，不截取前两个候选放行。

两模型臂相同固定 Qwen、温度、seed、4096 上下文及最多 1024 输出 token，每条各一次，不自动修复重试。最多 24 次本地生成，按现有候选资格预期最多 20 次；具体以执行计数为准。付费 API、云端、原生后端写入均为 0。输入整体预检不合格时保留阻断结果，不缩短原文后冒充同条件。

## 冻结、评分与推进条件

先保存源文件、自动候选、模型配置及实现哈希；评价文件仅作为不解析的字节文件封存。运行结束封存原始响应和预测，再打开参考评分。格式错误、调用错误、语义待审、覆盖不足分别统计。

报告确定案例的精确片段 TP/FP/FN、精确完整正确数、实际隐私准备成功数、未知案例的正确待审、参考敏感片段的完整/部分/未遮挡、合法原文事实保留和实际调用数。遮挡覆盖使用位置，不能仅检查完整秘密字符串是否消失。合法事实保留不是下游回答正确或拒答减少。

进入更大独立实验的最低信号：相对于同材料新跑 direct，events 在确定案例的精确完整正确数和可准备数都不下降、至少一项提高；两个未知案例正确待审；已准备载荷没有参考敏感片段遮挡不完整。若不满足，保留负结果，不追加提示词调参调用来选最好成绩。P90/R95、新独立 64 题至少 63 题联合成功、历史 HTTP 200/null 归因、原生稳定性和创新度要求保持不变。

## 参考方法与创新边界

证据抽取、结构化关系和时间约束都有既有研究。Eider 联合学习证据与关系，并融合全文和证据预测，说明只保留抽取证据也可能丢失信息；本试验不是 Eider 复现。[论文](https://aclanthology.org/2022.findings-acl.23/)

结构化时间关系学习已研究事件之间的依赖。本试验只有有限的“当前/历史/曾经”规则，不能声称实现了通用时间推理。[EMNLP 2017 论文](https://aclanthology.org/D17-1108/)

BRE 已采用逐关系真/假提问和相关性筛选。因此二元提问或增加一个提取 Agent 本身不构成新颖性。[AKBC 2026 论文](https://aclanthology.org/2026.akbc-1.24/)

这里检验的是已有思想能否修复本项目的具体错误。论文贡献仍须来自安全迁移问题中可重复、可解释、优于充分基线的实证或机制，不能由组件数量推导。
