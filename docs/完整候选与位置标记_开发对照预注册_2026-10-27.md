# 完整候选与位置标记：开发对照预注册

日期：2026-10-27。额度开始时已用 56%，遵守 60% 上限。本轮只进行一次最多 24 次本地生成的诊断，不调参重试，不替代原论文验收条件。

## 依据与固定改变

上轮直接分类在 10 个确定案例中完整正确 7 个。两条正文因超过 2 个候选被阻断，另一个失败涉及同词的普通用法与组织名用法。旧程序在收集完整候选之后才检查数量限制，因此这两条原始结果各自的 3 个候选仍有完整记录。

新合同不改旧文件、标签或结果：核对旧预测封存及原生 proposal 捕获的哈希，核对原文、原始模型输出、提取参数、候选数量和位置。只有原状态正常，或唯一错误为 `candidate_limit_exceeded` 且全部返回候选可逐项重建时，才允许进入本轮。保留模型返回的完整库存不等于它没有漏掉真实实体；不补名称、不改候选边界、不根据评分筛选。

固定允许最多 12 个候选，并对实际完整请求重新做长度预检，不截断正文或候选。12 是资源边界，不是已证明的通用最优参数。原生模型输入是否完整依据旧固定实现与捕获链，不能只凭待审状态通过结构检查。

## 两臂与预算

- **plain**：完整原文与全部原始候选，直接分类。
- **marked**：给同一原文中的候选出现位置添加候选 ID 标记，其他系统指令、候选列表、输出类别与模型参数均相同。

标记只能包含候选 ID，不能写入标准答案、正确关系或人为类型。去除标记必须严格恢复原文；重叠或伪造标记产生歧义时显式阻断，不悄悄移除候选。输出的引用位置映射回原文，标记不进入迁移内容。

两臂各运行 12 条已曝光开发正文，总计最多 24 次本地 Qwen 生成。模型固定为原 Ollama 0.40.8 和已核验摘要的 Qwen3 4B，4096 上下文、1024 输出上限、温度 0、seed 42，单请求串行。两臂顺序按正文编号交替。请求统一预检；任一超长则不开始整批生成。无云端、付费 API 或原生后端操作；无自动修复重试。

## 评分与裁决

运行输入只来自原始正文、自动候选和固定敏感策略。先冻结源码、模型配置及材料哈希，参考文件只按字节复制；所有预测和实际脱敏轨迹封存后，才解析参考。

两臂分别报告确定案例完整正确数、可准备数、精确片段 TP/FP/FN、精确率和召回率、未知案例待审与误放行、实际完整/不完整遮蔽、合法事实保留及模型输出错误。阻断保留在分母，但不称为已发生泄露。事实保留不等于 Agent 回答正确。

plain 与旧硬上限 2 的实验比较只能作为开发诊断，因为本轮共同指令也增加了标记解释；不把差异完全归因于上限。marked 与本批 plain 的比较检验位置表示，只有两未知正确待审、确定完整正确与可准备均不下降且至少一项提高、已准备敏感跨度无不完整遮蔽时才考虑扩大。即使达到开发集 100%，也不自动达到独立验收或论文创新度。

## 已有方法

实体边界标记已有研究，包括 [Matching the Blanks（ACL 2019）](https://aclanthology.org/P19-1279/) 与 [An Improved Baseline for Sentence-level Relation Extraction（AACL 2022）](https://aclanthology.org/2022.aacl-short.21/)。本轮使用无需训练的 Qwen 多候选输入，属于借用其表示思想，并不是论文训练过程的复现，更不是新算法本身。

原目标保持不变：敏感检测 P≥90% / R≥95%、新独立 64 题至少 63 题联合成功、历史 HTTP 200/null 归因与原生环境稳定性，以及对充分强基线的可重复创新证据。
