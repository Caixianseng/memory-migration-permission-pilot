# 双向持久化记忆交换实验结果 2026年11月5日

> 公开版说明：本文报告本机留存证据的实验与审计结果。公开包支持冻结任务重评分和聚合核对；不包含原生客户端历史、账户配置、数据库或私有传输回执，不能据公开包独立重做完整原生审计。本版仅增加此说明并将证据链接改为公开投影，实验数值不变。

本轮96个主实验条件的真实模型输出已全部取得。WorkBuddy接收端使用消耗积分的HY3线路 `hy3-x`，另一端使用DeepSeek Harness的 `deepseek-flash`。当前固定分块选择性重建未通过预设优势门槛；安全交付机制获得本轮测试支持。

最终完整性审计已通过，96个主视图的原始答案、接收库内容、来源选择及恢复记录均完成绑定核验。另一次独立只读复核确认132份源结果与96份答案的当前文件哈希一致，晚到产物未进入交付。评分器与实验前冻结版本保持一致。

## 实验范围

12个独立合成项目，覆盖每个Agent 20、50、100条原始记忆和0%、10%、30%、50%撤权比例，共1360条原始事实。每个项目测试两个方向、四种方法，合计96个条件、768条回答。192个不同问题中，每组有121个满足全部来源仍获授权的合法任务；42个问题能够验证独立保密值的UNKNOWN回答，按接收视图去重后包含38个保密值。

Agent A是真实WorkBuddy HY3，Agent B是真实DeepSeek Harness Flash。两个方向分别生成源端记忆，经过权限撤销、网关封装和接收方独立SQLite导入；接收库关闭重开后，由独立读取进程取出指定批次，再交给另一端真实模型答题。这里验证的是实验拥有的持久化记忆库与跨模型交付，不是两款商业应用内部私有记忆数据库的直接互通。

## 四组结果

| 方法 | 按项目等权合法任务得分 | 合法题全部必需值匹配数 | 交付内容 / 回答中的保密值命中 |
| --- | ---: | ---: | ---: |
| 合法原文 | 100.00% | 121/121 | 0 / 0 |
| 整体删除 | 20.83% | 40/121 | 0 / 0 |
| 全部重建 | 86.46% | 99/121 | 0 / 0 |
| 固定分块选择性重建 | 77.72% | 95/121 | 0 / 0 |

主指标先在每个方向内部平均合法题得分，再平均两个方向，最后对12个项目等权平均。因此百分比与跨项目合并的题目匹配比例不同。匹配规则要求问题所需的全部参考值出现，但不等同于对矛盾和额外幻觉的完整语义审查。UNKNOWN也是有效格式的回答，不能将格式完整率解释为任务正确率。

选择性重建相对合法原文低22.28个百分点，探索性项目配对bootstrap 95%区间为[-33.02, -11.67]个百分点；相对全部重建的差为-8.74个百分点，区间为[-22.40, 4.70]个百分点。独立统计单位是12个项目，采用5000次配对项目重采样，区间是未进行多重比较校正的逐项探索性区间。

四组的交付内容和回答均未命中冻结的38个去重保密值。这是本轮精确值检测结果，不构成对所有语义泄漏的证明。强UNKNOWN题正确数分别为42/42、42/42、41/42、42/42。


源执行失败对主结果有实际影响：11个方法视图的被选产物触发来源合规阻断，主分析保留这些条件。另按预先声明的合规配对规则，保留四种方法所选来源都合规的16个项目方向，仍覆盖12个项目；其中合法任务得分为原文100.00%、全部重建97.92%、选择性重建95.83%。该补充分析中，选择性方法相对全部重建的交付包反而增加3.42%，源生成尝试增加102.33%，仍不支持资源优势。这个子集不替换主分析，也不证明模型输出错误均由分块设计引起。

## 安全与持久化验证

96个接收库均完成导入、关闭重开和内容哈希核验。24个旧整条记忆权限视图中，18个撤权视图全部被拒绝，6个零撤权视图通过权限检查；源端工具合规性另行判断。对24份实际批准交付包的副本分别执行重放、内容篡改、错误接收方测试，共72次，均被拦截；主实验文件和数据库保持不变。

两项真实多层A→B→A机制测试已完成。撤权后的旧派生记忆导出、撤权前封装但尚未导入的旧包均被阻断，使用仍获授权来源形成的新派生记忆才被导入。多层测试独立报告，不并入12项目主比较。

权限撤销在首次导入前生效，交付边界是接收SQLite的导入提交。本实验不主张收回已被对方读到的明文；本机可信控制器与权限库也是机制的前提。源端首先生成不可变文件，派生行在撤权后的交付阶段登记SQLite；不能据此声称初始派生行早已在撤权前进入SQLite。源模型读取的是经源库原始事实核验的投影文件。路径包含撤权比例标签，虽然源生成未提供未来撤权清单、测试题或参考答案，也不能称为完全比例盲法。

## 当前方案为什么未取得优势

本轮选择性方法按来源ID哈希预先分成两个固定块，不是“权限变化与语义关联联合分组”的D1算法。评分后的描述性影响统计显示：18个撤权视图共有36个块，35个需要重建，只有1个能够完全复用，17个视图两个块都受影响。分块过粗且撤销来源散布，复用机会很少。

选择性方法引用的源端生成尝试平均为每方向3.67个，全部重建为1.83个；这包括各自所需初始生成和已登记恢复，不能把它当作供应商物理请求数或费用。选择性方法相对全部重建的交付包字节量仅减少2.50%，正文反而增加6.07%，没有达到预设20%资源降幅，合法任务质量也没有达到相对原文下降不超过5个百分点的门槛。

因此，本轮不能把优于整体删除当成算法优势，也不能证明当前分块比全部重建更有效。下一轮可检验保留原始事实的细粒度证据缓存与权限依赖失效模块；这是待验证方向，不能以本轮结果声称已经有效。

## 尝试记录与费用

源端125个原始生成条件和7个已登记额度恢复，共132份源结果记录全部保留。其中106份成功可用，26份关闭尝试仍保留在账本中；关闭尝试包括恢复前额度故障、工具合规失败、输出截断、创建失败和输出缺失，不等于26个主实验条件失败。主接收端首轮94个有效输出、2个服务临时错误空输出；两个条件各补测一次，均得到完整真实HY3输出，合计98次接收端外层尝试。长路径问题只通过已有输出的本地回核解决，没有因此产生第三次模型请求，旧失败与费用记录仍在。

另有同一旧源会话在官方积分续跑提示后产生的新turn，写出了一份晚到原位置产物。该产物没有替换已冻结的恢复版本，也没有进入主交付；其额外续跑单列，费用和供应商物理调用数为未知，不将其算成第133份源结果。

WorkBuddy积分扣费、供应商实际调用数和上游完整系统输入不可从当前证据完整取得，相应项保持未知，不能按Flash单价换算或记零。主实验Flash端有110次可核验调用，记录用量合计410966个token，按记录价格估算费用约1.12456元；这是估算，不是供应商实际账单。两项多层机制另有4次Flash调用，独立列账。当前不能声称总金额更低。
