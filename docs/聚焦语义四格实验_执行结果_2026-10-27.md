# 聚焦语义四格实验：执行结果

日期：2026-10-27。实现执行者：**GPT-6.1 Sol，reasoning effort=ultra**。实验被测模型：本机 `qwen3:4b-instruct-2507-q4_K_M`，不是实现执行者充当实验模型。基线提交：`9081beeffde1a0055793ef1526fdedcfd27e6e4b`。

## 1. 结论

**本轮没有观察到真实迁移造成的语义损失，但发现了一个假名化条件下的缺失信息判断失败。** 四格合法题都为 **8/8**；缺失题原文格 S0、T0 都为 **4/4**，假名化格 S1、T1 都为 **3/4**。错误来自同一个英文开发故事的同一道题，在两个假名化格中重复出现，不能算成两个独立问题。

源、目标在原文条件下的 12 对最终请求逐字节哈希全部相同，假名化条件的 12 对也全部相同；每对回答相同。因而本轮没有源/目标运行波动，没有可归因于迁移的差异。合法题的迁移差异、隐私表示差异及交互差异均为 0；缺失题假名化正确率相对原文下降 1/4，两端幅度相同。

这不是“所有语义测试全绿”。工程链路完成、授权检查通过和模型给出了一个可合法恢复的值，仍不保证该值回答了被问的关系。本轮只支持把后续问题收窄为：**脱敏后，Agent 如何判断所问关系的证据不足、应返回 UNKNOWN。** 一道开发题不足以确立机制，更不足以证明新算法或论文创新。本轮已停止，没有追加调用、调提示或新算法堆叠。

## 3. 真实原生资格与授权

原生后端为 **Open WebUI 0.12.3 / Cognee 1.6.5 的官方 ASGI 路由、实际原生存储与认证**，每故事源、目标使用独立进程、数据库和实际身份，共 8 个实例。ASGI 调用没有物理 TCP 服务测量；这是精确对象 ID 原文读取，不是向量或语义检索实验。

每个实例创建 5 个独立普通账户，用普通账户表示可信用户/Agent 组合，**不是厂商原生 Agent IAM**。源内容先实际写入，再从官方 API 读取；目标写入仅使用该实际源响应正文，然后独立读取目标 API，核对逐字节内容、对象绑定、主体与读取关系。WebUI 额外核对 Note 的显式 user/read ACL；Cognee 资格限定为有限有效读取矩阵，没有宣称导出了完整原生 ACL 或原生 export/share 权限。

8/8 实例通过资格。两端读取矩阵每故事包含 4 个普通主体 × 2 对象，全部符合登记关系：合法 reader 获准，其余组合拒绝。未使用 FakeWorkerRPC、静态 JSON 往返或夹具原文补出目标结果。

源、目标分别拥有独立 `CurrentMemoryAuthority`、签名记录、请求绑定、准备结果和仅内存恢复映射。共享范围只包括同一逻辑题的**模型可见随机代号与候选顺序**；没有共享源准备能力充当目标证明，也没有重写签名 nonce。源恢复实时核对源 API；目标恢复实时核对源与目标 API。每个实际访问回调绑定本次主体、原生对象和内容哈希。

这仍是串行当前读取核验，不是分布式原子撤权。运行中的控制分别记录为：

|---|---|---:|
| 仅目标撤权 | 4 故事均 T 拒绝、S 保留 | 0 |
| 源撤权 | 4 故事均 S、T 拒绝 | 0 |
| 当前授权未知 | 4 次明确的 authorizer unavailable 故障注入，分类 unknown，不称真实后端故障 | 0 |
| 交叉用户 | 4 次签名主体范围拒绝；实际原生跨主体另由读取矩阵验证 | 0 |

本轮启动前，审查发现拒绝正文仅扫描 raw 字符串可能漏过 Unicode 转义值，已修为 raw 与解码后完整 JSON 全字段一起扫描；明文和转义键/值负向测试均通过。带注册敏感值的 403/404 不会被当成安全阴性；读取资格失败则停止依赖调用，当前核权证据异常则 unknown。

唯一错误为 `dev_en_paraphrase / Q3`：

> Who manages the budget for Juniper Field?

四条候选只给出 Juniper Field 的最终审批/备用审批、Maple Haven 的主要/替补联系人，没有预算负责人。独立参照为 UNKNOWN。S0、T0 都返回 UNKNOWN；S1、T1 都返回 F1，即把“最终审批人”当成了“预算负责人”。恢复出的 `Orin Bell` 是本主体有权读取的值，但关系答错。这是缺失信息判断失效，不是非法恢复、权限迁移故障或敏感检测收益。

该题 S1、T1 实际请求哈希都为 `e9373e67f5abbe5c67afd6badfe58bde768adfd9b8918ef1b2fce15a0f7a3be0`，回答也相同，因此不能解释为迁移或源/目标运行波动。
