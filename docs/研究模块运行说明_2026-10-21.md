# 统一授权与任务评测：运行说明

2026-10-22新增公开任务与原生目标入口，实际执行和运行方法见[原生目标接入与阶段裁决](原生目标接入与阶段裁决_2026-10-22.md)。旧记录中“未重跑原生产品”描述的是上一阶段，本轮已另行完成Open WebUI新运行。

在`F:\项目\agent安全`打开终端。默认仅需要Python标准库；本轮测试使用Python 3.12.7。每次输出使用新目录，避免覆盖历史证据。

## 1. 跑可分发的小样例

```powershell
python -B -m memory_migration_study demo --output results/study_demo
```

打开输出目录的`report.html`查看结果。`exact_groups`是相同读者集合分组，`reader_copies`是按读者复制，`reject_all`是整包拒迁诊断。正常无资源限制时，前两种强基线应该保持合法读取，且不新增未授权读取。

结果中的W+是已知越权内容披露，W−是已知合法访问损失，unknown表示证据不足。`finite_scope_safe=true`只适用于本次登记的主体、对象和接口，不代表所有攻击都被排除。固定回答器的得分属于`instrumentation_metrics`，不能写成真实大模型的效果。

## 2. 检查评价器能否抓住故障

```powershell
python -B -m memory_migration_study demo --output results/study_diagnostics --diagnostics
```

这些故障由研究程序主动注入，包括错误正文泄漏和副本权限过宽。检出只说明评价器能处理这些故障，不是厂商漏洞发现或新算法优势。诊断与正常强基线分开查看。

## 3. 复用你补充的149项测试工程

```powershell
python -B -m memory_migration_study demo --output results/study_with_legacy --legacy-project "memory_migration_permission_149tests_20261021/memory_migration_permission_pilot"
```

程序通过显式路径加载已有`scripts/migration_policy.py`，记录源文件哈希，调用其有限静态关系检查。该检查是模型交叉核对，不代替实际HTTP探测；原代码和归档不修改。旧模型有“容器所有者也能读”的语义，新参考模型的投影说明随结果保存。

补充工程自己的离线测试在其项目层执行：

```powershell
cd memory_migration_permission_149tests_20261021/memory_migration_permission_pilot
python -B -X utf8 run_offline.py --tests-only
```

这条旧工程命令需要pytest。`run_offline.py`完整模式还会核验历史原生响应，不启动原生产品。原`workspace_run.py`保留D盘路径，不适合作为本机直接启动三种产品的入口。包内`00_解压后先看.md`说明了环境恢复要求。

## 4. 准备公开数据候选

回到`F:\项目\agent安全`运行：

```powershell
python -B -m memory_migration_study prepare-gatemem --data-root datasets/datasets --output results/study_candidates --episodes-per-domain 1 --limit 20
```

只准备Office/Household首检查点以前的材料与来源信息。其权限为透明声明的受控策略，不能冒充GateMem的原始授权。候选保持`needs_review`；没有事实依据、授权说明和评价答案，就不进入真实模型主评分。

## 5. 外部证据与真实模型

`evaluate-evidence --bundle PATH --output DIR`用于重新评价符合统一合同的证据包。`probe-native --output DIR`在没有配置时输出`not_configured`，不会把参考后端自动当成原生产品。具体产品需要先核实响应适配、身份、分页、控制对象和副本清单。

可选模型连接器要求明确配置模型、接口、凭证环境变量、价格核验日期、累计费用和本轮上限。模板为`examples/study_demo/model_config.example.json`，缺省值不会通过付费预检。不要把编程代理使用的`gpt-6.1-sol / ultra`当成已经核准的实验API模型。连接器默认关闭；真实请求错误或usage不明时不自动重试，也不假设失败免费。账本仅支持单进程串行使用，费用按显式价格估算，尚未验证实际供应商接口。

研究结果可能包含原始文本和本地路径。`results/`、原始数据及149测试完整交接包均保持本地，不随仓库自动提交。是否已经运行、是否属于原生证据及模型调用数量，以对应运行清单为准。
