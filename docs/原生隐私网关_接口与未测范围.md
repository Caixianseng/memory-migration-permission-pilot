# 原生隐私网关：接口与未测范围

`memory_migration_study/native_privacy_gateway.py` 是外部可信主机中的发送与恢复资格基线。它不启动客户端、不创建网络服务、不写目标文件，也不提供原生ACL。当前只接受一个已获授权的 exact single-value 记录；`record.text` 应当就是值，不能把包含多个事实的段落当作该接口的单值。

准备接口：

```python
prepared = prepare_native_private_memory(
    packet, source_query, sensitivity_policy,
    broker=broker, sender_actor_id=sender_actor_id,
    actor_id=recipient_actor_id, agent_id=recipient_agent_id,
    workspace=target_workspace, request_id=request_id,
    authorizer=current_authorizer, detector=None, mode="rules",
)
```

`packet` 使用现有统一交接格式，由原 `NativeAgentBroker` 验证完整性、接收主体、期限、精确事实及当前授权。外部 `authorizer(record_id, actor_id, policy_version)` 必须明确返回 `True`。执行Agent与签名audience一致，workspace由可信主机参数提供，真实路径须位于本仓库results目录内，其目录名须与audience的workspace_id一致，并已有真实隔离`.git`边界。

目标目录只能包含`.git`和空的或尚不存在的AGENTS.md。准备过程复用原敏感检测、假名化和出口检查；源问题和记忆一起处理。检测不确定、政策缺字段或有未知字段、权限不足及不能形成完整单值PVT时均阻断，不退回原文外发。默认rules模式不调用模型；显式选择agent/combined模式时，detector采用原检测器的本地callable合同，模型成本必须另外记录。

成功结果含`agents_md`、固定`question`、安全摘要metadata和不可序列化的进程内request。`agents_md`只有一个完整随机PVT；原问题本体不写入原生文件。原问题中的敏感值仍经历同步替换，完整映射也未裁剪。原masked payload及最终原生文件／问题投影分别通过现有egress检查。

可信主机可以精确安装返回的文本：

```python
(target_workspace / "AGENTS.md").write_bytes(prepared["agents_md"].encode("utf-8"))
```

接下来实际客户端调用应由单独的、已限制工具和预算的运行器执行。本模块本身不会调用Qoder、Harness、Node或任何模型。

恢复接口：

```python
restored = restore_native_private_answer(
    client_answer, prepared["request"], current_sensitivity_policy,
    broker=broker, sender_actor_id=sender_actor_id,
    actor_id=recipient_actor_id, agent_id=recipient_agent_id,
    workspace=target_workspace, request_id=request_id,
    authorizer=current_authorizer,
)
```

恢复前重新验证完整包、当前记录版本与授权、主体、Agent、请求、完整策略及工作区路径；原生文件必须仍与本次发送内容一致。只接收本次导出的完整PVT或UNKNOWN，之后继续使用原`restore_answer`。UNKNOWN也必须通过当前权限检查；query-only token、其他请求代号、夹带原值、文件变化、撤权及旧请求重放均不得恢复。

每次恢复尝试都会消耗request，失败后也不能复用旧映射；需要重新准备合法新请求。request不能JSON／pickle序列化，不能把整个prepared对象写入报告。报告只能选择metadata和允许公开的合成输入输出，不得输出私有映射对象。

## 可直接运行的零模型示例

从仓库根目录运行：

```powershell
python examples/native_privacy_gateway_demo.py
```

也可显式提供尚不存在的results子目录：

```powershell
python examples/native_privacy_gateway_demo.py --output results/my_native_gateway_demo
```

示例使用标准库及项目现有模块，只启动Git init创建两个真实隔离Git工作区。它不启动客户端或模型，不读凭据、不联网、不删除任何已有路径；输出已存在时拒绝覆盖。源事实、业务敏感词表、授权策略均为手工合成；没有调用模型生成记忆或标签。

示例明确将PVT作为**模拟回答**，检查合法恢复、prepare后恢复前撤权阻断，以及请求重放阻断。输出报告固定标记`model_calls: 0`、`client_calls: 0`和`simulated_answer: true`。这些结果只是工程数据流和当前授权路径的见证，不是原生Agent实验、敏感检测准确率或下游任务正确率。

## 未测与不支持范围

- 新增[双端单值实测](原生客户端隐私交接_双端单值实测_2026-10-26.md)已通过本接口完成真实Qoder／Harness各一次问答，2/2核权恢复正确。范围仅为明确注册的合成单值、主机核权和受控原生工作区；未核验完整云端隐式上下文，不能合并成完整隐私任务或原生在线撤权成功。此前零模型演示仍单独标记为模拟回答，不回填成真实调用。
- 没有测未知实体的检测质量、生成时隐私标签质量或原检测P90%／R95%门槛；已知敏感值词表不能替代这些任务。
- 当前没有在线MCP/HTTP授权服务、通用多事实检索、摘要、多源派生、工具动作授权或真实多租户身份隔离。
- 不支持把多记录包裁剪成一条后绕过其他依赖的授权；当前多记录包直接拒绝。现有来源／策略最新性仍依赖可信主机及当前broker，未证明跨进程持久状态、防回滚或分布式事务。
- 已交付的明文不能被撤权“遗忘”。本模块通过外部恢复门控决定是否交付原值，不把PVT文件或原生上下文称为产品原生ACL。
- 注册值出口检查不能证明全面语义隐私。独立64题至少63题联合成功、原生异构后端稳定性及论文创新仍未验收。
