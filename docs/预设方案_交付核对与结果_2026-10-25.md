# 预设方案：交付核对与结果

日期：2026-10-25。按用户更新后的目标，交付对象是**预设本地方案的实现、实际对照、核验和如实报告**。代码与实验执行完成不表示隐私／效用验收通过。本轮没有追加云端模型调用。

## 1. 已实现的完整本地流程

可信宿主绑定用户、来源及执行Agent → 本地构建逐字事实或原文证据块 → 检测并记录敏感字段 → 签名绑定内容、来源、策略和版本 → 本地存储 → 迁移前核权与验签，失效标签重检 → 问题与记忆同步假名化 → 可选闭集字段提示 → 本地任务模型回答 → 再次核权、验证原文证据与代号 → 展示有权原值或保存失败。

原有模型事实构建保留为同期基线；新增原文证据块构建会保存更多内容，属于标准无损分块基线，不能称为语义摘要。字段提示只提供固定类别说明，不删除敏感候选、不授予权限。本轮实测没有支持把字段提示或独立检测器并集作为默认优化。

新增的三个可复用模块：

- [coverage_memory.py](../memory_migration_study/coverage_memory.py)：段落／句界分块、连续原文位置和覆盖证书；超长单句、容量不足或检测待审不截断放行。
- [query_intent.py](../memory_migration_study/query_intent.py)：固定本地模型的闭集字段分类、问题哈希与请求绑定；未知回退，错配报错；不接收记忆、评分答案或权限。
- [union_detector.py](../memory_migration_study/union_detector.py)：独立NER与Qwen的保守并集，任何成员待审使整体待审，保留各成员实际成本。每来源最多1次编码加2次生成，计算预算高于单NER。

## 2. 修复了什么确定的问题

**中文恢复边界。** 原程序使用 `isalnum()` 检查所有语言的词边界，错误阻断连续中文句中的“已发货”等正确答案。现区分Han字符与其他字母／数字／下划线词边界；敏感跨度重叠、当前来源授权、跨请求和query-only限制仍保留。此前6个保存的正确中文答案全部通过新的恢复重放；该重放0模型调用，不覆盖历史成绩，也不是重新运行模型。

**明确字段边界。** 原规则可能把 `Customer: 名称. Status: 状态` 整段当成客户值。现以引号外的明确新 `key:value` 分隔，保留 `Ltd.` 等名称内点号及引号内内容。它是字段语法修复，不是通用自然语言理解。

**组合调用计数。** 普通Qwen每段最多2次生成；独立NER还需额外编码。可信callable声明有限预算，模型回复不能自行扩大上限。缓存、组合和报告保留真实修复次数。开发检测计量器曾未识别并集的 `unknown: 0` 字段；已修复，并从保存的成员记录零模型重算成本，原预测和评分未改。

## 3. 补齐格式、校验位与日历检查

新的公共入口 [value_validation.py](../memory_migration_study/value_validation.py) 提供：

```python
from memory_migration_study.value_validation import detect_sensitive, validate_value

# 与原检测接口兼容，另外返回不含原值的 validation_annotations。
detection = detect_sensitive(payload, policy, mode="combined", agent=local_detector)
```

注记分别报告 `format`、`checksum`、`calendar` 的 `valid/invalid/not_applicable/unchecked`。中国18位号码检查数学校验位与出生日期的日历合法性；日期支持数字、中文和英文月名；邮箱与电话只作有限离线格式检查。

校验和参考[GB11643-1999官方标准及表1／2](https://zjw.beijing.gov.cn/Portals/0/zhuanti/fazhan/%E8%BA%AB%E4%BB%BD%E8%AF%81GB11643-1999.pdf)。数学校验通过不证明证件真实、属于某人或已签发；未联网核实邮箱、电话、地址或身份。未知证件体系保持 `unchecked`。

**无效校验位或日期不删除疑似隐私，也不改变原检测状态、片段、权限或脱敏决定。** 新模块是独立纯注记层，没有参与此前冻结神经模型的判定。已对开发＋保留共600份实际检测结果重放，确认原决定及原文件完全不变，追加模型调用0。最终保留试验使用的原有模块仍保持对应执行哈希；独立注记模块作为新增文件单列证明。

无需模型的可运行示例：

```powershell
python -B -X utf8 scripts/validate_sensitive_payload.py --input examples/study_demo/value_validation.example.json --output results/my_validation.json
```

四个自编候选均保留：无效证件校验位、无效生日、无效日期、无效邮箱格式能被标记。显式加 `--with-local-agent` 才启用既有固定本地Qwen；不会调用云端。

## 4. 九类敏感检测：原门槛未通过

独立新材料120条，开发80、保留40，中英文等量。开发和保留按模板族隔离；同文本私有／公开策略配对另行标识。保留集仅20个注册敏感片段、3个模板族，40行不等于40份独立业务材料。标签是自编受控参考，尚无独立人工复核。

冻结保留集一次运行的完整片段精确匹配结果：

| 条件 | TP／FP／FN | 精确率 | 召回率 | 待审 | 95%召回＋90%精确 |
|---|---|---:|---:|---:|---|
| 规则 | 6／1／14 | 85.71% | 30% | 0 | 未通过 |
| Qwen Agent | 11／9／9 | 55% | 55% | 0 | 未通过 |
| 规则＋Qwen | 11／10／9 | 52.38% | 55% | 0 | 未通过 |
| 规则＋GLiNER | 18／2／2 | 90% | 90% | 0 | 未通过 |
| 规则＋独立并集 | 11／11／9 | 50% | 55% | 0 | 未通过 |

类别与完整边界都必须相同才计TP；范围过宽会形成FP和对应FN，不能把精确边界漏配直接解读成同数量的原值泄露。实际完整／部分／漏遮另按任务输入评分。全部预测、错误、成本与策略配对结果均保存，没有为通过门槛改标签或重跑调参。

另有24次固定开发标签探针：更换组织标签能减少部分泛称误报，但未找回弱中文完整名称；结果不支持替换固定标签，未用于保留集调参。

## 6. 实际1／3／10次交接与动态见证

同一自编开发故事、独立权限域和缓存，真正执行56次prepare；不是按一次结果乘倍数。表内调用包含首次构建需要的编码，耗时包含构建、prepare、恢复仪器和框架，不含另行记录的模型加载／资产校验。

| 条件 | 1次：编码／秒 | 3次：编码／秒 | 10次：编码／秒 |
|---|---|---|---|
| 迁移检测 | 5／0.713 | 15／1.984 | 50／6.568 |
| 迁移检测＋正确缓存 | 5／0.696 | 5／0.679 | 5／0.799 |
| 生成标注 | 5／0.704 | 7／0.879 | 14／1.875 |
| 生成标注＋正确缓存 | 5／0.693 | 5／0.646 | 5／0.688 |

生成标签相对不缓存重复检测有节省，但普通正确缓存也能达到相同调用数，不能把缓存收益包装成独有优势。时延是本机单故事描述性结果，不是普遍速度保证。

五个真实受控见证通过：同版本策略全文变化触发重检；移除标签触发重检；准备后撤权导致恢复拒绝；旧任务重放拒绝；新签发合法记录恢复访问。每次合法交接使用新代号。恢复探针由程序选取有记忆依据的代号，只计为仪器检查，不是模型问答成绩。

旧未计时版与补齐计时版各实际142次编码，均保留并计入本轮成本。源撤权的原生跨平台同步、多父授权与并发事务不在这项本地见证结论内。
