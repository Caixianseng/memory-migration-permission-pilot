## 实现范围

实现了“本地授权读取 → 本地检测 → 问题与记忆同步假名化 → 云端单事实回答 → 本地再次核权恢复”的研究原型。原生读取与快照完整性校验沿用现有实现。授权由程序依据已冻结策略判断，模型检测到实体或声称具有权限都不能授予权限。

假名化是以随机代号代替原值，并在本机保留恢复映射。它保留业务关系和潜在推断线索，不等于不可逆匿名化。`privacy_mode=pseudonymize`目前是后续验证入口；当前验收未通过，不能据此自动外发真实私有材料。原文对照只限公开或明确合成材料。

| 模块 | 用途 |
|---|---|
| `memory_migration_study/local_detector.py` | 固定本地模型、结构化候选检测、最多一次格式或位置修复 |
| `memory_migration_study/privacy.py` | 规则、候选原文校验、同步替换和受权恢复 |
| `memory_migration_study/privacy_corpus.py` | 独立运行材料与评分标签、三种检测方式的离线评估 |
| `memory_migration_study/privacy_experiment.py` | 四条件对照、费用预检、公开材料本地审计报告 |
| `memory_migration_study/llm_worker.py` | 原有入口增加可选隐私层，旧配置默认仍为原文模式 |

恢复映射只保存在进程内存，绑定主体、请求、策略版本与来源。代号按请求生成；同一请求保持一致，不跨会话复用。映射禁止常规 JSON、pickle 与 dataclass 序列化，日志表示隐藏内容。这是应用层约束，不能抵御有权调试或读取本进程内存的攻击者。

仅接受 `UNKNOWN`、确切注册的单个代号，或可在授权非敏感记忆中定位的短事实值。未知代号、问题自行提供的事实、来源不明、权限变化、跨主体或跨请求恢复均被阻断。检测不确定、API失败、恢复阻断与模型返回UNKNOWN分别记录；拒绝文字中仍包含秘密也计入披露。

## 本地环境与运行

使用 [Ollama v0.40.8](https://github.com/ollama/ollama/releases/tag/v0.40.8) 和 [Qwen3 4B Instruct 2507 Q4_K_M](https://ollama.com/library/qwen3:4b-instruct-2507-q4_K_M)，项目便携目录为 `.runtime/privacy_agent/`，不会提交到 Git。服务只监听 `127.0.0.1:11435`，启用 `OLLAMA_NO_CLOUD=1`，一次运行一个请求。检测器没有文件搜索、修改文件、联网搜索或发送消息的工具；安装模型需要访问官方下载地址，实际检测请求只发向本机。

模型清单完整 SHA256：`0edcdef34593eac1aa2be9c7d06c432dcf81945adca5eca2f27662c18f168ba0`。权重 SHA256：`85e4a5b7b8ef0e48af0e8658f5aaab9c2324c76c1641493f4d1e25fce54b18b9`。安装包 SHA256：`04d1d43ac62c2deb0393307bb49fed7caf6b192de41bdd497aaa9488089d5552`。实际进程、模型加载和探针证据分别保存在 `.runtime/privacy_agent/runtime_receipt.json`、`runtime_probe.json`。

采用非思考模型、JSON Schema、4096上下文和最多1024输出token。对输入采用保守字节上界预检，不能适配时记为待审；它不是供应商分词器的形式化证明。该模型不接受 `think=false` 参数，因而直接使用其非思考模型变体，同时拒绝含thinking或工具调用的响应。没有云端检测回退。

```powershell
# 首次运行会下载约4.08GB官方资产并校验摘要；以后复用已验证资产
powershell -ExecutionPolicy Bypass -File scripts/setup_local_privacy_agent.ps1

# 120条检测评估，不调用收费模型。output必须为新文件，cache可供中断恢复。
python -B -X utf8 -m memory_migration_study privacy-detect-eval --runtime examples/privacy_eval/runtime.json --evaluation examples/privacy_eval/evaluation.json --detector-config configs/local_privacy_detector.json --cache results/privacy_run/cache.json --output results/privacy_run/detection.json

python -B -X utf8 -m unittest discover -s tests -v
```

环境实测为32GB内存、RTX3070 Laptop 8GB显存。两个短文本探针的冷启动约67.6秒、热调用约0.49秒；不能将单次探针速度当作一般吞吐量。模型加载约3.18GB显存，GPU总占用约4.8GB。

## 数据与评分

120条材料为程序渲染的自编合成文本，中英文各60条；80条开发、40条保留，模板家族与故事不跨集合。存在同内容不同策略的配对，合计116个唯一故事。评分真值由构造片段位置和独立策略生成，尚无人工复核，不能称为真实业务分布或外部基准。

`examples/privacy_eval/runtime.json`只包含文本和检测策略；`evaluation.json`单独保存评分标签。检测器不会收到评分答案。规则、Agent、组合分别评测；失败和待审保留在召回率分母中。精确率与召回率采用类别与边界完全匹配，字符覆盖作为补充指标。缓存绑定数据、策略、模型、提示及检测实现哈希，不自动追加调参或改写真值。

保留集验收目标是组合检测召回率≥95%、精确率≥90%，并且没有处理失败或待审。该门槛只适用于本次小型开发验收，不是全面隐私保证。

## 研究边界

当前只处理单个事实值或UNKNOWN，不支持金额计算、长摘要和跨用户共享。使用冻结快照中的主体和策略；恢复前撤权通过单元测试检查，尚未接入原生在线撤权。模型和规则都可能漏报，复述、同形字符、关联推断与累积重识别仍未被全面覆盖。

工程正确、检测通过或合法回答改善都不自动构成论文创新。必须分别报告检测质量、云端输入原值暴露、回答正确率、未授权输出、处理阻断与成本，不能把全部拒绝当成安全成功。
