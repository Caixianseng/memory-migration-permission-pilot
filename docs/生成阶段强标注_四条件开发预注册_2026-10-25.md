# 生成阶段强标注与迁移复核：四条件开发预注册

日期：2026-10-25。语义校正两轮已经完成，但没有产生角色删除或完整名称补全收益。本阶段停止沿同一生成提示反复微调，改为检验强检测所在阶段与标签复用。仍是Agent安全记忆权限迁移主线中的工程与效用检验，不声明新算法、通用互操作或创新成立。

## 1. 已有证据与可证伪假设

上一轮独立NER＋本地生成检测器并集在27个可准备合法请求中未见注册完整遮蔽缺口，但5个短问题显式待审，导致合法任务失败。原NER准备32/32，却有同一中文完整名在4个任务上的局部漏遮。

新假设：**在事实构建阶段对完整事实做并集检测、签名保存标签，迁移时核验当前授权与标签并独立检测问题，能否保留完整遮蔽，同时避免每次对短问题调用生成检测器的待审？** 如果完整标签没有改善、生成标注失败、迁移复核退化或合法联合成功没有提高，应保留负结果，不将减少调用本身当作效果成功。

签名认证标签与来源绑定，不证明实体识别语义正确；标签仍不是权限。新问题中的未知敏感实体、公开实体误遮和推断线索仍需单独检查。

## 2. 共同A构建与两个标签集

全部8个已暴露开发故事各做一次真实编号式ReferenceMemoryBuilder构建。模型只收到原source、固定构建目的与候选，不接收下游问题、评分答案或敏感真值。构建后确切事实、source_start/end及完整来源在四条件间相同，不用不同构建结果混淆标注效果。

保留原NER事实标签，另对每个同一事实文本独立调用实际并集检测：固定NER＋固定本地Qwen检测器＋现有规则。输入query为空，唯一memory是该事实，不能用任务query补全标签。原始成员响应、完整策略、源/事实哈希、实际调用及结果保留，以便独立重建标签而不重跑模型。

两套记录分别调用标准`MemoryLabelAuthority.build_record`签发，record_id可以不同，不能手改签名。用source ID/hash、exact span与content hash构造稳定fact_key核对对应；实际主体、执行Agent、epoch、来源及获授权事实范围相同。这是两种标注实验条件，**不代表两个独立授权来源**。任一事实并集标注失败，该故事整套并集记录不部署；所有失败记录和G/T任务仍留在分母。

## 3. 四条件

| 条件 | A标签 | B迁移/使用检查 |
|---|---|---|
| M | 原NER标签 | NER迁移检测，原流程基线 |
| U | 同一原NER标签记录 | 独立并集迁移检测，带原主体/生命周期绑定缓存的强基线 |
| G | 并集生成标签 | generation模式核验标签并独立NER检测query；无效标签按原规则回退，原因单列 |
| T | 同一并集标签记录 | two_stage模式保留有效标签，并用NER再次检查query与memory |

G/T传入真实builder及detector版本要求；签名/来源/完整策略或当前授权不满足不能直接复用。四条件仍走同一个exact-fact授权、真实JSON交接、假名化出口与恢复前再次核权，不修改旧默认配置。完整source仅在受信host用于验证，不作为交给不可信Agent的原生传输内容。

各条件保留32道合法题、8道越权题，共160行。越权请求应在检测/回答前被拦截。主成绩为原自由回答与原严格恢复；同一输出的精确补括号仍仅为次要分析，不剥离多余文字、不补全缺失token、不允许问题自行提供的值变成记忆证据。

## 4. 冻结、调用与证据

- 固定原8故事、任务、真值、模型摘要、本地Ollama/NER、提示及解码预算；随机顺序预先写入plan。全部模型阶段结束后才解析评分材料，阶段关闭后禁止追加POST。
- 输出必须新目录，完整归档生产package及真实脚本依赖；运行末检查归档清单和SHA未变化。不得覆盖既有v1/v2、遮蔽诊断或新原生前置资格工件。
- 最坏本地生成上限848：8故事最多8个fact，构建16，生成标注128，U在无缓存最坏情况下576，回答128。每个检测段仍最多2次，模型回答最多1次；计入所有失败与重试。超预算明确失败，不静默截断。
- 固定回环端点并在推理阶段阻止外网。没有DeepSeek或其他收费模型请求，新增API费用上限仍为0元。
- 物理调用按构建、write annotation、U迁移、answer分别分账；NER编码器与生成调用分别记录。共同构建成本、并集标签的一次性成本、后续每条件调用及缓存命中分别报告，不将共享/复用成本说成独立部署免费。
- 保存两套记录、标签集统计、事实对应、逐fact标注原始响应、原始回答和实际外发文本；不保存authority密钥或恢复映射。公开聚合不含原文和可恢复映射。
- 独立验证器重建160格、原始标注成员→标签、同exact事实/不同记录ID的关系、当前授权顺序、实际遮蔽、完整原始回答/严格恢复成绩与调用预算；工程测试与效果分别报告。

## 5. 判定与原验收

比较M/U/G/T完整分母的正确率、合法联合成功、未授权输出、注册敏感原值缺口、额外遮蔽、待审/UNKNOWN/恢复失败及成本。将同一问题同一事实的真实输入差异与实际标签变化对应，不能将随机nonce带来的一题波动归因于算法。

这仍是开发实验，不把已有材料重新称为保留集。工程流程跑通、标签复用减少调用或本批答对提高，均不满足原120条检测、新独立64题至少63题联合成功、原收费协议、真实跨后端与创新论证。未经新独立验收不报告接近百分百；没有充分证据时保持目标未完成。

本阶段开始累计额度17%，用户上限60%、新大任务软停止55%继续有效。原生Mem0环境安装在独立目录推进，不改模型环境或本阶段生产源码；原生桥接结果另记，不能借用前置安装成绩。
