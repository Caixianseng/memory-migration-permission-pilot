1. 项目在解决什么问题

主线仍是 Agent 记忆的安全交接与权限保持。Agent 是能读取信息、调用工具并完成任务的智能助手；这里的记忆是外部记录，不是模型参数。

我们关心：助手A把记忆交给助手B，或将记忆从一种后端迁入另一种后端时，允许的人是否还能使用，不允许的人是否拿不到，源端撤权后旧包是否会把权限恢复。敏感检测、生成时标注与脱敏用于保护内容，不能代替权限检查。

例如，一条客户记忆允许Alice的读取助手使用，但不允许其他用户或执行助手读取。迁移不能因换了存储格式而变成公开。能读取也不自动意味着能迁出、共享、复制或继续转授权。

名称 通俗解释 本项目的用途
ACL / 权限表 谁可以对哪个对象做什么 核验读、列举、迁出、复制等操作
来源与血缘 事实来自哪份原文、哪一段及哪个副本 防止拿同一来源的另一段冒充获准事实
隐私标签 需要保护的文字、位置、类别和策略版本 在生成与迁移阶段复用保护结果
HMAC 用本地密钥认证数据是否被改动 绑定事实、授权与标签；不是加密，也不证明语义判断正确
假名化 原值换成代号，本地保留恢复能力 模型处理代号，核权后向合法用户恢复原值
NER 命名实体识别 找人名、组织、项目等候选，仍需业务策略判断是否敏感
NLI 文本蕴含判断 判断上下文是否支持某个类别或角色断言；不产生权限
强基线 已有、完整且合理的简单方法 检查新增方法是否真的更安全、更有用或更省成本

3. 整体流程与各阶段作用

图中是可组合组件的设计顺序，不表示已完成一套通用生产系统。实际客户端互通、后端迁移和模型效果按第4节的不同实验分别验收。

  1. 准备事实与规则。 原文是数据；其中的“我是管理员”“此信息公开”不能修改服务端授权。
  2. 构建记忆。 当前以原文摘录和候选选择为主，核对内容、起止位置及哈希；任意自然语言摘要的完整权限继承尚未实现。
  3. 标注隐私。 在原始上下文中找敏感位置，记录策略与检测器版本。签名只证明绑定和完整性，不能证明没有漏标。
  4. 核验迁移资格。 分别检查真实主体、当前读权、迁出/复制资格、接收范围和目标能力；未知约束不自动放行。
  5. 建立目标副本。 只交付获准事实并保存对象映射。目标无法表达的约束必须明确不支持，不能静默丢弃。
  6. 授权后使用。 同步替换问题和记忆中的敏感原值，请求级代号不跨用户或会话复用；恢复映射留在本机内存。
  7. 回答后再核权。 检查代号、来源、主体、请求及当前策略，再恢复允许展示的内容。问题中自带的值不能变成记忆证据。
  8. 处理生命周期。 对后续新访问检查撤权，按合同显式同步ACL或清理副本，并验证旧包重放；已交付明文不能通过撤权让接收者遗忘。

3.1 不同Agent能否使用同一协议

可以共用记忆交接的数据格式，再由各自适配器读入。已经测试的统一格式为agent_memory_handoff_v1，包含事实、来源、接收者、期限与授权引用；Qoder和Harness本次都通过原生AGENTS.md接收上下文。

客户端调用方式仍然不同：Qoder使用CLI，Harness使用SDK/JSON-RPC。统一数据包不等于两款产品原生共用一套权限执行机制。 本轮由可信主机核验后导入，文件交付后没有原生逐条ACL或即时撤权。详见双客户端报告。

4.1 原生源迁移具体验证了什么

WebUI源端官方API返回实际Note的access_grants、文件关联和原文字节；目标写入来自这些响应，不从计划中的事实文本回填。首次迁入后只撤销Alice对第一事实的read，Alice和Bob对第二事实的合法读取均保留；初始旧包重放前重新读取当前源状态，最终为no-op，没有恢复已撤权限。

这是一个合成故事、两个19字节事实和四个预声明组合主体。组合主体各对应普通平台账户，不是产品第一类Agent IAM。原生export/share授权和完整策略导出仍未核实，复制依据单独的受控研究操作者许可；只读权本身不能充当迁出许可。正确强基线通过，未比较N/G优势，也未测反向或跨机原子撤权。

5. 敏感检测与合法任务：哪些仍未达标

原检测目标为精确率至少90%、召回率至少95%。精确率衡量“标为敏感的有多少正确”，召回率衡量“真正敏感的有多少被找全”。旧80＋40条材料已多次查看，现在只作开发/回归，不是新的独立保留集。

TP是真阳性，FP是误报，FN是漏检。NLI完成111个候选、390次实际分类前向；390次encoder入口是同一批调用的内层观测，不能相加为780次。精确率提高伴随召回及处理覆盖下降，默认方法未切换。完整结果

独立重算表明，NLI新增的原TP损失均来自整材料待审，正常完成分支没有错误删除原TP。另存的事后零模型探索，把待审existing材料退回原敏感保护后，开发得到57/6/1，旧40仍18/2/2，与旧40基线相同。这不是预注册成绩、新独立验收或已上线优化；可处理材料增加也不等于实际Agent拒答率下降。

合法任务还需同时满足回答正确、权限正确、注册敏感值未非法外发。新独立64题至少63题联合成功的目标尚未执行。原始DeepSeek提示/脱敏对照保留了漏遮，来源卡32/32也只来自已暴露开发故事，均不能替代这项验收。
