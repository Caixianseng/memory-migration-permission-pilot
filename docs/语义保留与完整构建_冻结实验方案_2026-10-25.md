# 语义保留与完整记忆构建：冻结实验方案

日期：2026-10-25。此轮按 `experimental-design` 与 `scientific-critical-thinking` 两个 skill 执行。此前目标回合属于有进展：已有代码、真实结果及 GitHub 发布；但完成审计证明整体效果仍未达标，因此目标继续保持 active。

**目标更新记录：** 用户随后将目标改为“你自己调用skills完成我们的预设的方案”，移除了要求保证“达到效果”的措辞。本轮按预设协议完成代码、实验和如实验收报告；任务交付完成与95%／90%效果验收分开判断。下文的检测门槛、数据分母、失败保留及未完成的未来研究边界均不变。最终结果见[交付核对与结果](预设方案_交付核对与结果_2026-10-25.md)。

## 1. 保留原目标和分母

原方案要求原值留在本机、本地敏感检测、请求级假名化、合法接收者核权恢复，覆盖中英文身份信息和业务机密；检测开发验收目标是完整片段召回率至少95%、精确率至少90%，待审和错误必须单列。生成时标注方案还要求实际构建记忆、来源与标签绑定、迁移失效重检、A迁移检测/B生成标注/C两阶段对照，并报告合法回答、抽取损失和首次构建成本。

目前原检测、生成标签和新NER实验均未证明这些要求全部满足。尤其：生成标注保留集只有6/12故事构建成功；最新精确源夹具没有运行上游构建，不能替代它。中文状态答案还存在已确认的恢复程序词边界缺陷。总体目标不改成“接入一个NER后端”或“通过工程测试”。

## 2. 机制与并行强基线

1. 修复中文证据边界。原来使用所有 Unicode 字符的 `isalnum()` 判定英文词边界，导致连续中文句中的正确状态被拦下。新的 Han 边界区分保留非中文词、数字、下划线、敏感跨度重叠、当前授权和请求检查。所有新条件共用修复后的恢复规则，不把它冒充新隐私算法。
2. 原文证据块基线。`CoverageMemoryBuilder` 依段落和中英文句界构建逐字源块，实际运行检测后才生成可签名标签；不改写、去重或删掉正文。完整覆盖证书记录候选位置与源哈希，整体待审时不能当作已存储。容量不足、无安全句界的超长单句不截断。该方案保存更多原文，是标准无损分块强基线，不是语义摘要或新算法。
3. 闭集问题意图。固定本地模型只读原问题，将其分类为既有9类字段、业务状态或UNKNOWN；不读记忆、权限或评分答案。问题哈希和请求绑定后，只将固定双语字段说明加入已经脱敏的问题。它不撤掉遮蔽，不放行未知敏感值，不合并长短名称的代号，也不赋予权限。分类失败回退原问题，错配直接报错。

意图会传递“用户正在问哪类事实”的语义侧信息，因此仍不提供全面语义隐私。此轮不以模型判定泛称为由删除敏感候选，避免同词真实名称被字符串白名单放行。

## 3. 全链路六条件

| 条件 | 构建 | 迁移检测 | 意图辅助 | 作用 |
|---|---|---|---|---|
| model_build_migration | 既有本地模型真实选取事实及标签 | 固定GLiNER混合分词 | 无 | 当前构建方法的同期基线 |
| coverage_migration | 原文证据分块并检测标签 | 相同检测器完整检测 | 无 | 区分减少抽取损失的收益 |
| coverage_intent_migration | 同一批分块结果 | 相同检测器完整检测 | 本地闭集分类 | 区分语义侧信息的收益 |
| coverage_intent_generation | 同一批分块结果 | 当前有效标签＋问题检测 | 同上 | 生成标注B条件 |
| coverage_intent_two_stage | 同一批分块结果 | 标签＋完整检测 | 同上 | 两阶段C条件 |
| coverage_raw_local | 同一批分块结果 | 本地授权明文参照 | 同上 | 合法原事实效用上限参照；只用于自编材料和本地模型 |

后三种私密条件均使用同一构建与同一回答模型，A/B/C完整保留。原模型构建和证据块构建是两个完整系统的比较，涉及事实选择和标注器两项差异，不能把全部差异仅归因于其中一项。分块的额外存储量、每次检测量必须报告。

每个任务的条件顺序按种子2026102502打乱；固定模型、阈值0.5、授权参照、恢复规则和预算。每个合法任务只分类一次，多个条件共用这项安全字段结果；物理分类成本只计一次，条件成本须按相应实际需求分配。构建也仅实际执行一次后用于相同家族条件，不能把分配成本和物理总调用相加。

## 4. 独立数据、开发和保留

新的自编数据由单独的数据准备过程编写，运行文本与评分文件分开，未使用此前8故事的模型结果来选择样例。

- 全链路故事：开发8、保留16，中英文各半；故事每个4合法题、1越权题。开发4模板族，保留8模板族，模板族不重叠。保留含18敏感片段和8公开组织片段。
- 检测材料：开发80、保留40，中英文各半，覆盖原9类。保留含20个注册敏感片段、3个模板族和18对同文本不同策略样例；这40行不能当作40个独立故事。与24个故事没有共享来源。
- 语料文件 SHA-256 在各自 manifest 冻结。根代理在实现冻结前只查看开发数据，保留原文与标签只在固定实现的运行与事后计分阶段读取。
- 正式保留结果不用于本轮调参。若失败，保留失败和当前版本，后续改动需要另一批独立材料；旧保留集只作回归。

标签为自编程序核验，尚未独立人工复核；位置和答案在原文只能证明机械可定位，不能证明自然业务标注正确。样本小、模板相关，均报告描述性结果，不用重复任务扩大独立样本数或宣称普遍安全。

## 5. 指标与失败归因

全链路保留全部登记故事和任务。分别报告构建成功、必要事实仍在记忆、实际写库文本量、预处理阻断、模型UNKNOWN、恢复失败、最终答对。抽取失败或丢失的秘密不算成功脱敏。原文源块覆盖是候选覆盖；只有整体成功时才写入受控记录。

外发同时检查问题和记忆的完整/部分/未遮敏感片段，以及公开内容额外遮蔽字符。注册金标不是所有可能敏感信息，因此零缺口也不是隐私证明。越权按迁移是否准备、回答模型是否调用、最终输出分别查验，不用模型不复述来抵消底层放行。

检测主指标按主体来源、类别及完整边界精确匹配。非ok结果不产生“接受的预测”，已登记敏感值保留为漏检分母；另报经过校验的候选指标，防止规则部分结果被混为完整成功。精确率在零预测时为null；无待审/错误是单独条件。按语言、类别、政策配对分层，不用低召回换高精确率。

本轮三项主机制不解决任意条件式业务策略、语义推断泄露、自由摘要、多源派生或原生在线撤权；它们仍在完整研究路线的未完成清单里。实际1/3/10次生命周期迁移也不能用算术成本投影冒充。

## 6. 执行与完成审计

先运行新模块工程安全测试，再运行开发故事和开发检测。开发阶段可定位接口缺陷，但记录所有真实调用与失败。实现通过后冻结包源码和脚本哈希，保留集只运行一次，不自动追加调参请求。模型均为现有本地固定Qwen与GLiNER；外部网络连接禁用，新增云端API预算为0元。

只有原目标要求的检测、合法任务、权限不变量、构建保留与所需交付全部有对应证据时才能关闭目标。此文不是完成声明。每个阶段的测试、实测、源码与输入哈希分别保存；绿色工程测试不替代隐私和效用验收。
