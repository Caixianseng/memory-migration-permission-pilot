# 扁平闭集判型：真实结果与裁决

日期：2026-10-26。结果目录：`results/flat_candidate_detection_20261026_v1`。本轮是原 80 条开发材料＋40 条已暴露回归的工程对照，不是新保留集验收；没有改变默认方法。公开汇总见 [aggregate JSON](../benchmarks/flat_candidate_detection_20261026_summary.json)。

**裁决：扁平闭集判型未通过原检测门槛。** 预先指定主方法 `primary_boundary_full_no_prior` 在开发集的召回率为 56.90%，在旧 40 条回归中为 30%；不能因已接受结果的精确率为 100% 就宣称检测成功。标准 boundary-only 是主比较基线，而不是只与旧五字段的较差结果比较。

## 1. 实际做了什么

可信主机给每个固定位置候选分配 CID。模型仅从当前策略允许的 `VALUE_类别` 或既有非值角色表达中选一项，主机据此恢复类别、实体类型和固定证据引用。输出是闭集分类，没有新增业务名称词表，也没有产生权限。

三个缓存条件来自已发布的原始合成诊断包，ZIP SHA256 为 `330d31c9e70980631dd3b67dc8a059512af77693e39870c2b8570b696effce43`：原 NER＋规则、标准 boundary 修正、旧五字段 all-candidates。它们保留历史 168 次编码、81 次生成的成本记录，本轮未重跑神经编码。

四个新条件预先固定为：局部窗口＋旧类型提示；局部窗口＋不显示旧类型；完整来源＋不显示旧类型；以及**标准 boundary 候选池＋完整来源＋不显示旧类型**。最后一个是冻结主方法。原候选池在开发集只能覆盖 55/58 个参考片段，低于 95% 的最大可能召回；boundary 后可覆盖 57/58，旧 40 条两种池均覆盖 20/20。因此原池三条件用于机制比较，不能冒充合格主方案。

全部条件继续保留格式类保护、显式策略声明、位置绑定、重复与边界闭合；不确定或非法判别导致整条材料待审，所有参考敏感片段仍计入漏检分母。检测阶段没有权限提升，也没有运行下游回答或原生 Agent 迁移。

所有新条件各有 81 次本地生成，39 条无候选材料不调用生成模型。没有格式修复重试，合计 **324 次真实本地 POST、107,420 个输入 token、8,127 个输出 token、新增编码 0**；注册总上限 960 次。云端模型调用与新增 API 费用均为 0。编码为 0 不表示没有神经模型计算；Qwen 的本地生成是本轮真实模型工作。

## 3. 失败主要发生在哪里

四个新条件的待审数分别为 65/120、70/120、42/120、42/120；阶段错误均为 `decision_semantic_uncertainty`。主方法是开发 27/80＋旧回归 15/40，共 42 条。模型输出中一旦有候选被判不确定，主机按冻结合同阻断整条材料；并未把它当成安全的空检测，也没有删除分母。

这能解释接受结果的 P 较高而总召回明显降低。它不是“全部标题误报已解决”的证据，也不是下游合法用户拒答减少的结果。本轮没有测合法回答；新增待审反而提示后续效用风险。

在这一次配对中，完整来源条件比局部窗口条件少待审；删除旧类型提示没有改善局部条件。这里仍不能得出“完整来源普遍更好”“旧类型造成锚定”或“JSON schema 是根因”：旧五字段与 flat 同时改变了提示词和输出合同，模型与材料规模有限，且没有单独干预字段顺序。相关一手资料与限定见[机制资料核验](结构化判型与原文位置投影_资料核验与机制裁决_2026-10-26.md)。

## 4. 证据与独立核验

实际协议与结果文件是 `plan.json`、`materials.json`、`model_calls.json`、`unscored_rows.json`、`model_phase_closed.json`、`score_phase_started.json`、`rows.json`、`report.json`。固定公开包中的原材料、9 个历史实现及本轮 16 个源码文件均核对哈希。

[独立验收脚本](../scripts/verify_candidate_decision_diagnostic.py)对真实结果执行了 **2557/2557 项一致性检查**，回执 `independent_decision_verification_v1.json` 为 passed：核对闭合前后制品、324 次调用归属、四条件原始阶段假传输回放、历史控制复核、全部 840 行独立评分和汇总、原候选池资格及强保护。独立验收未调用模型。**检查通过表示保存结果可核对，不表示算法通过检测验收。**

固定模型为 `qwen3:4b-instruct-2507-q4_K_M`，完整摘要 `0edcdef34593eac1aa2be9c7d06c432dcf81945adca5eca2f27662c18f168ba0`，Ollama 0.40.8；4096 上下文、最多 1024 输出 token、temperature=0、seed=42。模块为 `optional_closed_candidate_decision_v1`，提示为 `position_bound_single_label_v1`。公开 JSON 附模型、协议、源码与回执哈希，仅含汇总，不含材料原文、评分答案、认证信息或恢复映射。

验收脚本早期在 **plan-only** 检查中误将公开 ZIP 的包装 `README.txt` 要求纳入成员清单；其全 ZIP 已固定摘要，修正 verifier 后资格检查通过。该失败回执留存，未修改任何材料或真值。本次真实结果的 2557 项验收回执已通过。

## 5. 本轮收敛

继续保留标准 boundary-only 为完整强基线，保留本次负结果，不把 flat 条件换成默认方法。原目标 P≥90%、R≥95% 尚未在新独立保留材料上成立；当前旧回归也未满足两项门槛。后续判别器、格式或策略适配必须使用独立冻结材料，分别测漏检、额外遮盖、待审和下游合法效用，不能依靠把已暴露材料反复调到满分来证明泛化。
