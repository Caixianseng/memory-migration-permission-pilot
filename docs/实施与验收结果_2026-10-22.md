方案开始于2026-10-21，最终运行于2026-10-22。实现由用户指定的`gpt-6.1-sol`、`ultra`推理设置子代理完成，主任务独立审查并运行最终测试。研究方案见[具体实验与论文判断](研究方案_具体实验与论文判断_2026-10-21.md)，程序入口见[运行说明](研究模块运行说明_2026-10-21.md)。

## 1. 本轮交付

- 独立`memory_migration_study`包，保留原`memory_migration_pilot`。
- 三态共同授权、真实用户与Agent凭证绑定、实际目标主体ID映射、源对象到多个目标副本映射。
- 对read/list分别检查所有登记副本及完整分页；扫描原始响应、JSON键和值，错误状态中的正文也可构成披露。
- 正确分组、按读者复制、整包拒迁；源保持、源回导、目标等效配置；明确标注的人工故障诊断。
- 同一检索管线的授权参照／迁移／无记忆三组，按源ID去重、固定并列排序、随机组序、独立上下文。合法事实任务与应拒绝任务分别评分。
- 复用补充工程`migration_policy.py`的静态关系检查，保存原模块路径及哈希，不修改原文件。
- 少量GateMem候选准备、统一HTTP合同与证据包复算入口；默认关闭的可选模型连接器及预算预检。

用户后续补充的工程位于`memory_migration_permission_149tests_20261021/memory_migration_permission_pilot`，已经纳入复核和静态检查器接入。其原生服务虚拟环境没有随包提供，当前没有重新启动产品实验。

## 3. 新演示结果怎样理解

以下合并两个自编故事，仅用于验证仪器。W+/W−的计数单位为主体—源对象—操作，read和list分别计算。合法任务共4道，另有2道应拒绝任务。

| 条件 | 已知W+ | 已知W− | 未知 | 合法事实任务答对数 | 含义 |
|---|---:|---:|---:|---:|---|
| 正确分组exact_groups | 0 | 0 | 0 | 4/4 | 正确简单方法保持了本样例权限与任务 |
| 按读者复制reader_copies | 0 | 0 | 0 | 4/4 | 同上，没有体现复杂算法必要性 |
| 整包拒迁reject_all | 0 | 14 | 0 | 0/4 | 无新增披露，但合法内容与任务全部丢失 |
| 人工500错误正文泄漏 | 8 | 0 | 0 | 4/4 | 模型上的ACL正确，也不能代替实际接口检查 |
| 人工多余副本越权 | 8 | 0 | 0 | 4/4 | 登记的另一个副本也必须检查；静态检查亦检出unsafe |
| 人工删除一次探测／故事 | 0 | 0 | 2 | 4/4 | 任务能答不代表底层已完整验收，安全结论保持null |

表中的回答由固定程序生成，仅进入`instrumentation_metrics`，**不是真实LLM成绩**。授权参照与正确迁移的合法任务损失为0，拒迁为1。人工泄漏场景即使合法任务全答对，也不因此变得安全。人工partial条件可出现访问关系损失而本组任务不受影响，仅作为说明两个指标不同的诊断。

## 4. 独立审查实际修复了什么

审查发现原检测只扫描JSON值，键名中含受限正文会漏判。保留相同403响应的独立回放：修复前W+=0且错误判safe=true；修复后W+=1、safe=false。JSON转义键也纳入回归。原失败记录没有覆盖。

见[修复前独立记录](../results/review_new_evidence_boundaries_20261022.json)和[修复后独立记录](../results/review_new_evidence_boundaries_fixed_20261022.json)。另外验证了漏测副本、未核身份和分页证据缺失必须为unknown；候选配置不能改变共同授权参照；进程崩溃留下未结算费用预留时不能继续请求。
